# CATAN — ローカル4人テーブル

Next.jsが画面、Python / FastAPIが盤面と対局状態を担当する学習用アプリです。
`test` とは別のアプリで、ポートは **3002 / 8003** です。

## 今できること

- 指定した9港を、指定した交差点ペア・交換比率に固定。
- 港を船・資源のイラストで表示（3:1 / 2:1は表示）。
- 4つのチェックボックスを組み合わせて地形と数字を生成。
- 同じ対局を、全体表示と4つの個人用タブで共有。
- 人間4人が順番にサイコロ2個を振り、出目順で座席を確定。
- 同点者だけを振り直し。確定済みの順位グループを追い越さない。
- 確定した席順で、開拓地→つながる道を1人ずつ2巡配置。
- 初期配置の距離ルールを判定し、2軒目の開拓地に隣接する資源を自動で受け取る。
- 自分を6時に表示し、通常対局では他人の手札は裏向き。AI観戦では個人用タブも含め、常時全員分の手札を公開。
- 通常手番のダイス、生産、7の手札破棄、盗賊移動・略奪、手番終了。
- 道・開拓地・都市・発展カードを、資源コストと接続条件を確認して建設。
- 銀行との4:1・港交易、発展カード、最長交易路・最大騎士力、10点勝利。
- 最大3候補の対人交渉、成立時の自動交換、全拒否または逆交渉（1手番5交渉まで）。
- プレイヤーごとに人間／コンピューターを選択。P1だけ人間、または4人全員AIのプリセット。
- AIは順番決め、初期配置、通常手番、建設、銀行交易、交渉・逆交渉、盗賊、発展カードを自動操作。
- 観戦モードではAIの操作を盤面へ一手ずつ反映。再生・一時停止・1操作送り・4段階の速度変更に対応。
- AIを含む4人全員の個別画面を開け、対局途中でも人間操作とAI操作を相互に切り替え可能。

**まだ実装していないもの：強さを学習する機械学習AI、対局の永続保存。**
初期配置が終わると各人は開拓地2軒・道2本・公開得点2点になります。
手札や得点を見せるために、架空の初期カードを配ってはいません。

## 自宅外のスマホから遊ぶ（Tailscale）

Tailscaleを使うと、アプリを一般公開せず、許可したスマホだけが自宅外からゲームPCへ接続できます。
この方式では、Next.jsの3002番とPython APIの8003番をLANやインターネットへ直接公開しません。

詳細な初回設定は [Tailscale接続ガイド](docs/tailscale.md) を参照してください。設定後は、次の3つを起動します。

**ターミナル A: Python API（PC内だけで待機）**

```powershell
cd C:\Users\okome\Documents\CATAN\catan_app\backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8003
```

**ターミナル B: Next.js（PC内だけで待機）**

```powershell
cd C:\Users\okome\Documents\CATAN\catan_app\frontend
npm.cmd run build
npm.cmd run start:tailscale
```

**ターミナル C: Tailscaleの閉域HTTP中継を有効化**

```powershell
tailscale serve --bg --http=80 http://127.0.0.1:3002
tailscale serve status
```

`tailscale serve status` が表示する `http://...ts.net` のURLを、TailscaleでゲームPCを共有した参加者だけに渡します。
HTTPS証明書を発行しないため、証明書透明性の公開台帳にはURL名を記録しません。ブラウザにHTTPの警告が表示されることがありますが、通信経路はTailscaleで暗号化されています。
`tailscale funnel`、ルーターのポート開放、Cloudflare Tunnelは使いません。

PCと同じWi-Fiに接続したスマホでは、PCのIPv4アドレスを使います。このPCで現在使っているURLは
`http://192.168.0.128:3002`です。IPアドレスは再接続や再起動で変わる場合があるため、つながらない場合は
PowerShellで`ipconfig`を実行し、「IPv4 Address」を確認してください。
スマホの通信は3002番のNext.jsへ集約し、Next.jsがPC内部の8003番へ中継します。したがって、スマホから
Pythonの8003番へ直接接続できなくても、画面表示とゲーム操作ができます。
IPv4アドレスが変わった場合は、`frontend/next.config.ts`の`allowedDevOrigins`も同じ値へ変更します。

両方のターミナルを起動したままにしてください。止めるときは各ターミナルで **Ctrl + C**。
すでに起動中なら、同じコマンドを重ねて実行せず、ブラウザを再読み込みします。

## 4つのタブで遊ぶ手順

1. 最初の画面で生成ルールを選び、「ゲームスタート」を押す。
   人間と遊ぶ場合はAIにするプレイヤーへチェック。デバッグなら「P1だけ人間」または「4人全員AI」を選ぶ。
   AIの動きを画面で追う場合は「AIの動きを観戦する」もONにする。
2. 作成画面は「全体表示」になる。12時から時計回りにP1・P2・P3・P4が座る。
3. 「4人の操作画面」のリンクを開く。P1〜P4それぞれが別タブになる。
4. 各個人用タブでは、そのプレイヤーが6時になる。操作可能な本人のタブだけで「サイコロを振る」が有効になる。
5. 最初はP1 → P2 → P3 → P4の順に振る。同点があれば、そのグループだけ再投する。
6. 全員の順位が一意になった時点で、全体表示の12時から時計回りに出目順で並び替える。
   席順確定後は、各プレイヤー席の順番決め用ダイスを非表示にする。記録は折りたたみの「サイコロの記録」で確認できる。
7. 個人用タブは、その確定席順を回転して自分を6時に表示する。その後、席順は変わらない。
8. 順番決定の1位から、各自のタブで「開拓地を置く」候補をクリックし、右側の「配置を確定する」を押す。続いて、黄色い候補線から、その開拓地に接する道を1本置く。
9. 1位→4位まで終えたら、4位→1位の逆順で同じ操作をもう一度行う。2軒目の開拓地を置いた直後、その周囲の砂漠以外のタイルに対応する資源が入る。
10. 8本目の道まで置くと初期配置は完了する。先手がゲームを開始し、通常手番へ進む。

## AI対局を観戦する手順

1. 「4人全員AI」を押し、「AIの動きを観戦する」をONにしてゲームを開始する。
2. 作成直後から標準速度で再生する。順番決め、初期配置、通常手番の各操作が盤面へ順番に反映される。
   全体表示・個人用タブのどちらも4人全員の資源カードと発展カードが表向きになる。
3. 右側の「一時停止」で止め、「1操作進める」で好きな場面を確認する。
4. 再生速度は1.5秒、0.75秒、0.3秒、0.1秒から選べる。

観戦モードをOFFにすると、従来どおりAIは人間の入力が必要な場面または勝敗決定までまとめて進みます。
人間とAIの混合対局では、人間の操作待ちになると再生を停止します。人間が操作した後に、全体表示で再生を押してください。

デバッグでAIの操作を途中から引き継ぐ場合は、いったん観戦を一時停止し、マスター画面の「人に切替」か、そのAIの個別画面にある「人が操作する」を押します。個別画面の操作ボタンが有効になり、その時点の状態から人が続けられます。「AIに戻す」で再びAI担当になり、マスター画面から観戦再生を再開できます。

発展カードは購入した手番には使えませんが、次の自分の手番からはサイコロ前にも使えます。騎士の盗賊移動・略奪や街道建設を解決した後は、サイコロ前の画面へ戻ります。盗賊は盤面のタイルをクリックして選択し、「このタイルに盗賊を移動」で確定します。その後、隣接する対象プレイヤーを選び、その人の資源から1枚をランダムに奪います。

### 通常手番の画面操作

- 「建築・貿易・交渉・発展」の4つから選ぶと、その操作だけが展開されます。発展カードの購入も「発展」にあります。
- 資源・駒・銀行在庫などが不足する操作は押せません。建設では必要資源と押せない理由を表示します。
- 都市は「建築 → 都市にする」を選び、盤面の黄色い円で囲まれた自分の開拓地をクリックします。
- 盤面右上に手番プレイヤー、進行状況、この手番の出目を表示します。次の手番は「まだ振っていません」に切り替わります。
- サイコロは盤面中央で約1.7秒の立体アニメーションを表示します。出目はPythonで確定済みで、演出によって変わりません。AI観戦の自動進行は演出終了を待ちます。
- 使用済み発展カードは、通常対局でも全員に表向きで表示します。同種のカードは枚数をまとめて表示し、座席の高さを変えません。
- PC幅（981px以上）では画面内に盤面を固定し、右の操作・ログ欄を独立してスクロールできます。狭い画面では縦に並べ、操作欄の中を独立してスクロールできます。

順番決定用のサイコロでは資源は生産しません。
個人用画面は**座席表示だけを回転**し、盤面・港の向きは全員共通にしています。
Tailscale接続では、Next.jsをPC内の `127.0.0.1:3002` に限定し、Tailscale Serveが許可済み端末へだけHTTP中継します。
同一Wi-Fi内で遊ぶ場合は、従来どおり `npm.cmd run dev` とPCのLAN IPv4アドレスを使います。

通常のカタンは最高の出目の人を先手にして、既存の席順で時計回りに進みます。
このアプリの「全員を出目順に並べ替える」方式は、今回指定されたハウスルールです。
[公式ルールブック](https://www.catan.com/sites/default/files/2021-06/catan_base_rules_2020_200707.pdf)

## 盤面生成のチェックボックス

| 画面の名前 | 条件 |
|---|---|
| 砂漠を中央に固定 | タイルID 9を砂漠にする |
| 6・8を隣接させない | 6同士・8同士も含め、赤数字のタイルが辺を共有しない |
| 6・8を4種類の地形に分散 | 4枚の赤数字を、異なる4種類の資源地形に1枚ずつ配置。残り1種類には配置しない |
| 同じ地形のつながりは2枚まで | 辺でつながる同種地形の集まりが最大2枚。離れた2枚組が複数あってもよい |

初期値は「6・8を隣接させない」だけONです。
OFFの条件は強制しません。偶然その条件を満たすことはあります。
砂漠には数字を置かず、盗賊を置きます。地形枚数・数字マーカーの内訳は変わりません。

同じseedと同じ生成条件なら、同じコードで同じ盤面を再現できます。
条件を満たす地形と赤数字配置を探す処理には上限を設けています。

## タブ間の同期と非公開情報

- Pythonのメモリに対局を保存します。ブラウザの再読み込みでは同じ対局へ戻れます。
- **Pythonの再起動で対局は消えます。** `--reload` によるPythonコード変更時の再起動も同じです。DB保存・再開機能は未実装です。
- タブは約1秒ごとに最新状態を取得します。出目はブラウザではなくPythonが抽選します。
- 各操作に対局の更新番号（revision）を付け、古い画面や手番外からの操作を拒否します。
- 同じ操作IDの再送は二重に実行しません。同時操作もロックで順番に処理します。
- 個人用リンクには、その席専用のトークンが含まれます。HTTP要求では `X-Player-Token` ヘッダーに入れます。
- 通常対局ではPythonは本人の資源内訳・発展カードだけを返し、他人については合計枚数だけ返します。AI観戦を選んだ対局はデバッグ用に全員の手札を公開します。使用済み発展カードはどちらでも公開情報です。
- 初期配置の候補も、現在置く番の本人だけに返します。開拓地候補は隣接する開拓地を除外し、道候補は直前に置いた開拓地に接する辺だけです。
- 自分の得点には非公開の勝利点カードを含めます。他人に見せる公開得点には含めません。
- 最長交易路・最大騎士力は所有者の席にバッジを付け、盤面下にも所有者を表示します。獲得判定自体は今後の実装です。
- 作成者には4人分の参加リンクを渡します。本人だけに配布してください。これはローカル学習用の簡易参加方式で、インターネット公開用のアカウント認証ではありません。

作成者のタブでは参加リンクをsessionStorageに保存するため、同じタブを再読み込みしてもリンクを表示できます。
タブを閉じると失われる場合があります。リンクを失った場合も、既に開いた個人用タブは続けて使えます。
「新しい対局を作る」は別の対局を作成する操作で、既存タブの対局は置き換えません。

## API

- `POST /api/games`：対局作成。公開対局情報と4人分の参加用トークンを返す。
- `GET /api/games/{id}`：最新状態。トークンなしは全体表示、ありは本人向け情報。
- `POST /api/games/{id}/order-rolls`：その手番の本人だけが順番決めのサイコロを振る。
- `POST /api/games/{id}/initial-placements`：その手番の本人だけが初期開拓地または初期道路を置く。
- `POST /api/games/{id}/ai/run`：AI操作を指定ステップ数まで実行。観戦画面は1ステップずつ呼び出す。
- `POST /api/games/{id}/players/{player_id}/controller`：本人用トークンで、その席を人間操作またはAI操作へ切り替える。
- `GET /api/health`：起動確認。

作成リクエスト例：

```json
{
  "seed": 42,
  "rules": {
    "desert_center": true,
    "red_numbers_not_adjacent": true,
    "red_numbers_distinct_terrains": true,
    "terrain_clusters_max_two": true
  }
}
```
