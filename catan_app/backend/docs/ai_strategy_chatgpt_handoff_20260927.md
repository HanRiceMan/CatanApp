# 相談したいこと

4人用カタンの自作アプリで、AIをより強く、人間らしくしたいです。現在は「強い既存PPO + Pythonの計画層」というハイブリッドが最も強く、計画層の判断を段階的にPPOへ移す実験をしています。

これまでの経緯、採用済みの方針、失敗した実験、現在の実装状況を以下にまとめます。まず状況を整理したうえで、次の開発方針を提案してください。コードそのものより、優先順位・実験設計・評価指標・中止条件を相談したいです。

特に次の3案を比較し、推奨する順番を理由つきで示してください。

1. 発展カード購入判断のPPO移行を継続し、入力特徴量と教師ラベルを改善する。
2. 計画層を残した現行最強AIを起点に、交渉込みのリーグ戦・自己対戦で強化学習する。
3. PPOへ移す対象を発展カード以外へ変更する、または計画層を一部恒久的に残す。

「計画層を外すこと」自体を目的にはせず、最終的な強さ、人間らしさ、保守性を重視してください。

## プロジェクトの前提

- 個人学習用の非公開アプリで、一般公開・配布は予定していません。
- フロントエンドはNext.js、バックエンドとゲームAIはPythonです。
- 最大4人で遊び、任意の席を人間またはAIにできます。
- スマホからはTailscale経由で自宅PCへ接続します。
- 最終目標の一つは、現行のルールベースAI3人を相手にした4人戦で、学習AIが安定して高い勝率を出すことです。当初の目安は80%でした。ただし、評価相手が弱すぎることで見かけの勝率だけが上がることは避けたいです。

## 現在のAI構成

### 1. 現行最強AI

- アプリ上の表示名: `現行最強AI`
- モデルID: `ppo_gnn_board_65k_s03_exp_v003`
- Observation v2、GNN階層型候補ポリシー、377 Action Spaceです。
- PPO単体ではなく、開拓・都市・道路・発展カード・初期配置・盗賊・交渉などに関するPythonの計画層や補助判断を組み合わせたハイブリッドです。
- これまでの多数の小規模評価では最も安定して強く、以後の教師・比較基準として扱っています。

### 2. 盗賊PPO移行AI

- アプリ上の表示名: `盗賊PPO移行AI（実験版）`
- モデルID: `ppo_robber_value_73k_s01_exp_v001`
- 現行最強AIをベースに、盗賊の移動先・奪う相手の価値判断を専用PPO/残差ヘッドへ移した実験モデルです。
- Observation v5（1722次元）を使い、盤面状況に加えてベイズ推定した相手手札情報を参照します。
- 自動評価では現行最強AIを完全には上回っていませんが、人間との実戦では盗賊配置に大きな違和感がなく、実際に人間へ勝った試合もありました。そのため削除せず、選択可能な実験AIとして残しています。

### 3. 発展カード購入判断の移行候補

- Observation v6（1747次元）と専用の発展カード移行ヘッドまでは実装済みです。
- まだアプリのAI選択肢には追加していません。
- 教師あり事前学習の候補が現行最強AIの対戦成績を維持できていないため、昇格させていません。

## AI設計に関する基本方針

### 盤面拡張

- 開拓地と都市の建設数・建設機会を重視します。
- 開拓地は最大5個なので、6拠点目相当の生産力を目指す場合は、少なくとも1つを都市化して駒を戻す必要があります。
- 道は「合法だから」ではなく、その先の有望な開拓候補、港、資源補完、競争、最長交易路など、明確な目的がある場合に伸ばします。
- すでに他プレイヤーの開拓地や道路で先が閉じている道、発展性のない行き止まり、他人の道路へ意味なく突っ込む道を減らします。
- 盤面的に今の道路網から有望な開拓地を置ける状態なら、資源が揃う前に無目的な追加道路を建てず、基本的には開拓地を待ちます。ただし、競争に先行する、より価値の高い候補へ伸ばす、港へ接続するなどの例外はあります。
- 目先の固定目標に固執せず、手札・盗賊・盤面競争・交換可能性が変わるたびに、開拓地、都市、道路、発展カードの完成までの見込みを再評価します。

### 初期配置と初期道路

- 初期道路は、現在の交差点の価値だけでなく、次の開拓候補、港、相手との競争、初期手札から先手を取れる確率まで見ます。
- 3人の道路が一点へ重なるような無理な競争、相手の開拓地で既に発展先が塞がれた方向、自分の道路を実質的に潰す方向は避けます。
- 相手と競争する場合は「自分が木・レンガを得やすく、相手より先に伸ばせる見込み」があるかを考慮します。

### 発展カード

- 「3拠点未満では原則買わない」のような固定ルールにはしません。
- 開拓地・都市をしばらく作れない停滞時の打開、盗賊を退かすための騎士、最大騎士力が現実的な場合、余剰資源の有効活用などで購入価値が上がります。
- 一方、建設へ直結する資源を消費して成長を遅らせる購入や、終盤に低確率の勝利点カードだけを狙う購入は抑えます。
- 9点だから一律に発展カードを禁止する、都市資源を固定予約する、といった硬いルールは避けます。勝利までの最短・最も確実な経路をその都度比較します。
- 最長交易路と最大騎士力は選択肢であり、常に取るべき目標ではありません。盤面によって捨てる判断も必要です。

### 交渉

- 現在の目的に対して余っている資源、とくに8枚以上で「7」によるバースト危険がある手札は、希少資源との交換を積極的に提案します。
- 例: 羊1・小麦4で石が取りにくい盤面なら、小麦1対石1だけでなく、必要なら小麦2対石1も候補にします。
- 交渉は単なる価値の等価交換ではなく、建設までの待ち時間短縮、バースト回避、相手を利する度合い、盤面上の資源希少性を考慮します。
- 現状、プレイヤー間交渉はPPOの377アクションに完全統合されておらず、補助ロジックの責務が大きいです。将来、交渉を学習対象へ含める場合はAction Space拡張と、提案・逆提案・受諾を含む別設計が必要です。

### 相手手札推定

- 手札推定は強化学習で覚えさせるのではなく、ゲームルールに基づくベイズ推定として実装し、その推定結果をPPOの入力へ渡す方針です。
- 資源獲得、建設、銀行・港交換、発展カード購入、豊作、「7」で捨てた資源など、公開情報は確定更新します。
- 「7」で捨てたカードの種類は実物のゲームでも公開される前提で、秘匿情報にはしません。
- 主な不確実性は盗賊でランダムに奪ったカードです。盗賊が複数回発生すれば不確実なカードも累積するので、「隠れるのは常に1枚」とは扱いません。
- プレイヤーごとの独立推定だけでなく、全プレイヤーの手札と銀行在庫を合わせた資源総数の保存制約を使い、同時分布を整合させます。
- 現時点では、巨大なパーティクルフィルタを全面採用するより、公開イベントによる厳密更新 + 盗賊由来の小さい不確実性を列挙・重み付けする方式を優先しています。不確実性が膨らんだ場合だけ枝刈り・集約が必要です。

## これまでの学習・移行方針

1. 現行最強AIをいきなり置き換えず、強いハイブリッドを教師・比較基準として残す。
2. 計画層を一度に全部外さず、盗賊、発展カード購入など、判断領域を一つずつPPOへ移す。
3. 最初は教師あり学習で現行判断を再現し、性能を壊さない初期値を作る。
4. その後、自己対戦・リーグ戦の強化学習で、教師の模倣を超える。
5. 同一seed・席順ローテーションで、元モデルと候補を比較する。
6. 小規模評価はスクリーニングにだけ使い、昇格判断は最低40戦程度と人間による実戦観察を組み合わせる。
7. 悪化した候補は現行AIへ上書きせず、実験記録だけ残す。良い候補も、まず別の選択肢としてアプリへ追加する。

## 盗賊判断の移行で分かったこと

- 盗賊配置では、単に生産量が高いタイルを塞ぐのではなく、現在の首位・勝利への近さ・相手が欲しい資源・自分が盗みたい資源・味方への被害を考慮する必要があります。
- ベイズ推定した手札情報をObservationへ追加し、専用の盗賊価値判断を学習させました。
- 自動40戦評価では現行最強AIに対し、候補の勝率が概ね27.5%前後で、元のハイブリッドの37.5%前後を下回りました。ルールAI相手では候補が82.5〜85%程度勝つ評価もありました。
- PPOのsoft-target anchorを追加した実験では、現行最強AI相手の勝率が27.5%から22.5%、ルールAI相手が85%から82.5%へ悪化したため不採用にしました。
- 一方、人間との実戦では、盗賊の置き方に大きな違和感がなく、候補AIが人間へ勝利しました。自動評価だけで切り捨てず、実験版として残しています。

## 発展カード購入判断の移行で分かったこと

発展カード購入だけを専用残差ヘッドへ移し、他の行動ファミリーは元PPOを維持する方式を実装しました。初期値は元モデルと完全一致するようゼロ初期化しています。

### Observation v5だけを使った実験

- 学習60試合、検証15試合。
- 学習458例、検証125例（発展カードを買える状態だけを抽出）。
- 検証データで教師の購入率は27.2%、元PPOは68.8%でした。
- 強い補正でも予測購入率は32%程度、二値一致率は72.8%程度にとどまりました。
- 一度8戦を通った候補も、独立40戦では悪化しました。
  - 現行最強AI相手: 元35.0% / 候補27.5%
  - ルールAI相手: 元82.5% / 候補77.5%
- 結論: v5だけでは、なぜ教師が「今は発展を買わず建設を待つ」のかを区別できません。

### Observation v6を追加した実験

発展判断向けに25特徴を追加しました。主な内容は次の通りです。

- 現在買えるか、既にこの手番で買ったか。
- 接続済みの合法な開拓候補数と候補価値。
- 開拓地・都市の完成までの推定待ち時間。
- 発展カードを買う前後で建設待ち時間がどれだけ増えるか。
- 盗賊で妨害されている生産量。
- 最大騎士力までの距離。
- 購入理由の内訳。
- 未購入発展カード山札からの各カード確率と期待価値。
- 元PPOの行動ファミリーlogit。

75試合のデータでは、検証上の教師購入率23.4%に対し予測24.2%、二値一致率83.6%まで改善しました。しかし対戦では、同じ8試合で現行最強AIの平均得点7.625に対し候補6.875、ルールAI相手も9.375に対し8.125へ悪化しました。

さらに300試合（学習240、検証60、学習2107例、検証536例）へ増やしても、二値一致率は学習83.9%、検証83.2%で頭打ちでした。つまり、単純なデータ不足より「入力に足りない判断材料」または「教師ラベルの文脈依存・曖昧さ」が原因と考えています。

## 現在考えている次の改善候補

発展カード判断を続けるなら、次の「直近の建設進捗」をObservation v6へ追加する案があります。

- 開拓候補へ向かうために必要な道路が今すぐ建設可能か。
- 道路1本で新しい合法開拓候補が開くか。
- 銀行・港交換を1回行えば開拓地または都市を即建設できるか。
- 現在の接続済み開拓候補が相手に先取りされる危険度。
- 都市化できる自分の開拓地数と、各候補の生産増加量。
- 開拓地、都市、発展カードそれぞれについて、必要資源の不足ベクトルと期待獲得ターン。
- 現在の手札がどの目標へ自然に近いか。
- 7枚超過リスクと、発展購入がバースト対策として持つ価値。
- 交渉または銀行交換を含めた到達可能性。

ただし、次の候補は最低でも教師との発展購入二値一致率90%以上を目安にし、それを満たすまで対戦評価へ進ませない案です。90%が妥当か、また多クラスの行動一致ではなく二値一致を主指標にしてよいかも相談したいです。

## 避けたい失敗

- 3拠点未満、9点時など、局面を単一条件で縛る固定ルール。
- 都市用資源、開拓用資源を長期間固定予約し、手札が変わっても方針転換できなくなること。
- 目標を固定したため、より早い勝ち筋や停滞打開策を無視すること。
- 開拓候補があるというだけで道路・都市・発展カードを常に禁止すること。
- 教師あり一致率だけを高め、実際の勝率・平均得点・順位を落とすこと。
- 8戦程度のばらつきで昇格判断すること。
- ルールAIへの過学習で、現行最強AIや人間への対応力を落とすこと。
- 現行最強AIを実験モデルで上書きし、比較基準を失うこと。

7. 評価指標。勝率だけでなく、平均得点、順位、開拓・都市・道路・発展カード数、停滞ターン、無駄道路、盗賊価値なども含めてください。

- 発展カード購入の教師ラベルは、最終的な行動だけでなく、各選択肢の価値差や反実仮想を持つsoft targetにすべきでしょうか。
- 現行の計画層を教師とすると、その癖や限界まで学習します。いつ教師模倣から自己対戦RLへ切り替えるべきでしょうか。
- 勝率を壊さず一部判断だけをPPOへ移すには、残差ヘッド、オプション/階層型ポリシー、DAgger、offline RL、distillationのどれが適していますか。
- 計画層の一部を恒久的に残した方が合理的でしょうか。残すなら、ルール整合・ベイズ推定・合法手マスク・短期探索・長期戦略のどこまでが妥当でしょうか。
