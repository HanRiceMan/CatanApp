# GNN初期配置固定・PPO継続学習実験（2026-09-23）

## 目的

教師あり学習済みの初期配置GNNを固定し、`ppo_hierarchical_50k_v001` の通常手番だけを追加学習する。評価では学習前後に同じ100ゲームseed（120001〜120100）を使用した。

## 学習率 3e-4（元モデルと同じ）

## 次の判定

1. 現在の50kモデルを正式モデルとして維持し、今回の追加学習モデルは昇格しない。
2. PPOの学習ログにKL・clip率・entropy・value lossを保存し、方策を壊す更新が発生していないか診断する。
3. 5,000 step後だけでなく短い間隔でcheckpointを評価し、改善後に再劣化していないか確認する。
4. 必要なら学習率だけでなくclip rangeまたはKLによる早期停止を一条件ずつ比較する。
5. 複数seedで安定して改善した条件だけを、未使用評価seedで最終確認する。

プレイヤー間交渉は今回のRL環境では全Agent無効、銀行・港交易は有効である。

## gamma比較

55k基準モデルから、rollout 1,024、学習率3e-5、追加10,240 stepを固定し、`gamma=0.995` と `gamma=0.999` を3学習seedで比較した。評価は全モデルで同じ100盤面（170001〜170100）。基準モデルは勝率34.0%、平均得点7.40、平均順位2.230だった。

| 0.995 | 20261401 | 38% | 7.49 | 2.160 |
| 0.995 | 20261402 | 32% | 7.20 | 2.285 |
| 0.995 | 20261403 | 36% | 7.42 | 2.220 |
| **0.995平均** | - | **35.3%** | **7.37** | **2.222** |

0.999は3 seed平均で基準より勝率2ポイント、平均得点0.04点、平均順位0.03改善した。ただしseed 20261402では勝率33%に下がり、効果は小さく学習seed依存も残る。さらに初回seedでは20,480 stepまで続けると、0.995は38%から34%、0.999は38%から36%へ悪化した。

したがって、0.999を今後の候補gammaとして記録するが、現行モデルを置き換える明確な改善とは扱わない。MLPへの学習時間追加とgamma調整は頭打ちと判断し、次は報酬・対戦相手・Action Spaceを変えずに、通常ターンの盤面候補をGraph Encoderで表現する限定GNN比較へ進む。

### Graph Family教師あり事前学習

ルールAIが選択したAction Familyを教師として、200ゲームから11,338件、検証50ゲームから2,684件、独立テスト50ゲームから2,916件を収集した。既存Actorは固定し、Graph Message PassingとGraph Family残差だけを学習した。

- 事前学習前の独立テスト一致率: 26.51%
- 事前学習後の独立テスト一致率: 80.73%
- 最良epoch: 29
- 検証loss: 0.4319

Family分類そのものは十分に学習可能であることを確認した。一方、残差を100%適用した50局評価では、勝率18%、平均得点5.66、平均順位2.95まで低下した。さらに1,024 stepのPPO微調整後は勝率10%、平均得点5.32、平均順位3.04となった。

主因は、ルールAIのFamily模倣が既存PPOの長期戦略と一致しないことである。特に発展カード使用Familyのテスト一致率が0%で、騎士使用が基準の平均2.60回から0.08回、最大騎士力の獲得率が42%から2%へ低下した。単純な分類精度を対局性能の代理指標にはできない。

| 75% | 28% | 7.22 | 2.29 | 44% | 56% |

弱い混合では発展カード使用の壊滅は避けられたが、全条件が基準を下回った。したがって、教師AIのAction Familyをそのまま模倣する方式は採用しない。

GNNを主軸とする方針自体は維持する。採用済みの通常ターンGNNは、道路・開拓地・都市・盗賊といった**盤面上の候補比較**にGraph情報を使い、完全未使用200盤面で有意な改善を示している。次段階ではFamilyを外部教師へ置換せず、既存PPOのFamily分布を保ったまま、候補Actionの価値推定・補助損失・盤面表現を強化する。

## 共通Family内のGraph候補事前学習

Family戦略を壊さないため、元PPOとルールAIが同じ空間Family（盗賊移動、道路、開拓地、都市）を選んだ局面だけを収集し、そのFamily内の候補だけを教師あり学習した。Family Head、非空間Action、Critic、既存候補Headは固定し、Graph Message Passingと通常手番のGraph候補残差Headだけを更新した。

200/50/50ゲームから、学習2,170件、検証551件、独立テスト538件を取得した。候補一致率は17.66%から21.19%へ上がったが、未使用100局では次のように悪化した。

| 条件 | 勝率 | 平均得点 | 平均順位 |
| --- | ---: | ---: | ---: |
| 学習前 | 35% | 7.48 | 2.215 |
| 候補模倣後 | 27% | 7.22 | 2.335 |

Family選択や発展カード使用は保護できたが、ルールAIの候補を正解として強制すると、既に強いPPOが学習した配置判断を上書きする。

候補教師lossに、元PPOの合法候補分布から離れすぎないKL lossを追加した。同じ1,104件の学習データ・同じ50評価局で係数1、3、10を比較した。

| 1 | 28% | 7.16 | 2.37 |

次は外部教師の一手を正解にせず、実際の終局結果・Value target・PPO advantageからGraph表現を学ぶ。GNN方針は維持するが、「Heuristicに似せるほど強い」という仮定は破棄する。

## 実対局Outcome / Advantageによる候補学習

現行GNN-PPOを確率的に対戦させ、各通常手番について割引returnとCriticのValueを保存し、`advantage = return - value`を計算した。空間候補のうち高advantageだった実行Actionを強めるAdvantage Weighted Regressionを実装した。Family Headは固定し、Graph候補Headだけを更新し、元候補分布へのKLアンカーも維持した。

- 学習200局: 3,098候補
- 検証50局: 759候補
- 独立テスト50局: 819候補
- 学習データのadvantage平均: 0.0148
- advantage標準偏差: 0.5436
- 正advantage率: 29.4%
- Family内訳: 盗賊1,558、道路1,324、開拓地78、都市138

独立テストのweighted NLLは`2.0254025 → 2.0253904`で、実質的な変化はなかった。検証lossによる最良checkpointはepoch 1だった。

未使用100局（360001〜360100）の結果は学習前後で完全一致した。

| 条件 | 勝率 | 平均得点 | 平均順位 | 最長交易路 | 最大騎士力 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 学習前 | 31% | 7.46 | 2.295 | 57% | 56% |
| Outcome学習後 | 31% | 7.46 | 2.295 | 57% | 56% |

終局結果は一手ごとの空間候補に対して分散が大きく、現行データ量ではKLアンカーを超える安定した更新信号にならなかった。学習率を上げて変化だけを作る実験は、既存戦略を壊す可能性が高いため実施しない。

次段階は、教師模倣や後付けOutcome回帰ではなく、タイル・交差点・辺を別ノード種として相互にMessage Passingする異種GNN v2を、既存方策とlogit一致するゼロ残差からPPOで学習する。報酬・Action Space・相手AIは固定し、複数seedと早期checkpoint選択で純粋に盤面表現の差を比較する。

## 異種GNN v2

現行の54交差点Graphに加え、19タイル・54交差点・72辺を別ノード種として扱う2層の異種Message Passingを実装した。

- Tile → Vertex
- Vertex → Tile
- Vertex → Edge
- Edge → Vertex

現行GNNの全パラメータを移植し、異種Graph残差Headの最終層を0初期化した。移植直後は全377 Action logitがビット単位で一致する。現行ActorとFamily Headは固定し、異種Graph Encoder、空間候補残差Head、CriticだけをPPO更新した。

学習率3e-4、追加5,120 step、共通評価50局（380001〜380050）の3 seed結果は次のとおり。基準は勝率28%、平均得点7.28、平均順位2.29。

| 学習seed | 勝率 | 平均得点 | 平均順位 |
| ---: | ---: | ---: | ---: |
| 20261911 | 32% | 7.36 | 2.25 |
| 20261912 | 26% | 7.10 | 2.39 |
| 20261913 | 30% | 7.26 | 2.29 |
| 3 seed平均 | 29.3% | 7.24 | 2.31 |

勝率平均は+1.3ポイントだったが、平均得点と平均順位は悪化し、seed依存が大きい。3指標すべてが改善したseed 20261911だけを完全未使用200局（390001〜390200）で確認した。

| 条件 | 勝率 | 平均得点 | 平均順位 | 最長交易路 | 最大騎士力 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 現行GNN | 28.0% | 7.270 | 2.2875 | 56.5% | 51.0% |
| 異種GNN v2 | 24.5% | 7.105 | 2.3825 | 57.0% | 48.5% |

検証盤面の改善は完全未使用盤面で再現せず、全体性能は明確に悪化した。異種Graphの追加自由度に対して現在のPPO rollout量が不足し、検証seedへ過適合したと判断する。異種GNN v2は正式モデルにもUIにも登録しない。現行の `ppo_gnn_board_65k_s03_exp_v003` を維持する。

この結果はGNN全体を否定するものではない。現行GNNは完全未使用200局で元MLPを有意に上回っている。一方、より深く複雑なGraphへ進めば自動的に強くなるわけではない。次はモデル容量を増やさず、現行GNNの学習データ効率・checkpoint選択・Value安定性を改善する。
