# 停滞・戦術価値に応じた発展カード購入（2026-10-01）

## 方針

「3拠点以上」のような固定拠点数条件は使用しない。2拠点でも建設が停滞していれば発展カードを選択できる一方、拠点数にかかわらず今すぐ開拓地・都市を建設できる場合は建設を優先する。

通常の購入条件は次のとおり。

- 開拓地・都市を今すぐ建設できない。
- 有益なプレイヤー間交渉を先に試しても解決しない。
- 最短の開拓地・都市建設まで推定4ラウンド以上かかる。
- 発展カード購入による建設の追加遅延が1ラウンド以内。
- 同じ手番では適応戦略による購入を1枚までとする。

次の場合は戦術価値を持つため、停滞条件とは別に購入理由へ加える。

- 自分の建物に接する盗賊によって4pip以上の生産が止まっている。
- 自分が8点以上で、勝利点カードを含む別の勝ち筋が必要。
- 最大騎士力の必要数まで、保有騎士を含めて2枚以内。

山札のカード確率は、公開済みの使用カードと自分だけが知る手札を除いて推定する。相手の非公開カードや実際の山札順は参照しない。
