# ベイズ手札推定と盗賊改善（2026-09-29）

## 目的

現行PPOが鉱石4へ盗賊を偏らせる問題に対し、相手の公開得点・生産と、公開資源移動から
推定した手札を用いて盗賊の移動先と被害者を選ぶ。

## 情報境界

推定器は相手の実手札を直接参照しない。次を確定情報として更新する。

- サイコロ産出と初期配置でもらう資源
- 道路・開拓地・都市・発展カードの公開費用
- 銀行・港交換と成立したプレイヤー間交渉
- 豊作と独占による資源移動

盗賊による1枚の移動と、7で捨てた資源の内訳は確率分布として扱う。盗賊の当事者だけは
実際に見えた資源を使える。第三者の推定では `private_resource` を参照しないことをテストした。

資源を使った公開行動は条件付き観測として扱う。例えば道路を建てた相手について、
木材とレンガを持たない候補状態を除外してから各1枚を減らす。

## 評価

探索50局では勝率60%→76%、平均得点8.80→9.20。独立100局では勝率63%→71%、
平均得点8.65→8.99、都市2.07→2.38だった。独立100局の勝率差95%区間は
-2〜+18ポイント、都市差は+0.08〜+0.55。

盗賊の鉱石配置率は独立100局で60.8%→17.4%、出目4は276/485回→20/459回。
特定の鉱石4へ寄る癖を解消し、首位と自分が必要な資源の推定を反映した。

## 道路評価

最長交易路の2手先評価と相手道路との競合回避も比較したが、探索50局・独立100局とも
勝率と最長交易路獲得率は変わらなかった。そのため本番設定には採用せず、判断ログだけを
追加した。次回の人間対戦から、道路ID、相手建物による終端、競合交差点、現在と次手の
最長道路長を確認できる。
