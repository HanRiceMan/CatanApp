# 候補共有型PPO：初期配置固定アブレーション（1万step）

## 目的と条件

前回の1万step比較では候補共有型の初期配置が大きなボトルネックだった。今回は学習者の初期開拓地・初期道路を既存Heuristicに任せ、**通常ターンだけ**MLP-PPOと候補共有型PPOで学習・比較した。ゲームルール、報酬、Observation v2、Action Space v1、相手Heuristic×3、PPO設定は共通。両モデルとも学習seed `20260923`、1万stepで新規学習した。前回モデルの単なる推論時の初期配置差し替えではない。

評価は未使用盤面seed `40001`〜`40100`。Player IDを回し、相手をHeuristic×3とHeuristic×1+Random×2にした。各モデル200対局、計400対局。両モデルの初期2開拓地は全対局で同一だった。非法Actionと打ち切りはいずれも0。実験設定・対局単位の結果・モデルは `experiments/candidate_fixed_setup_10k_s20260923/` に保存した。

| 評価相手 | MLP 勝率 / 平均VP / 平均順位 | 候補共有 勝率 / 平均VP / 平均順位 | 候補共有−MLP（勝率 / VP） |
| --- | --- | --- | --- |
| Heuristic×3 | 6% / 5.35 / 2.91 | 23% / 6.73 / 2.45 | +17ポイント / +1.38 |
| Heuristic×1 + Random×2 | 13% / 5.83 / 2.27 | 39% / 7.37 / 1.76 | +26ポイント / +1.54 |

同じseed・Player ID・席で対応させた差のbootstrap 95%区間は、Heuristic×3で勝率差 +8〜+26ポイント、VP差 +0.83〜+1.95。混合相手では勝率差 +15〜+37ポイント、VP差 +0.99〜+2.10。これは**この1学習seedでの評価盤面変動**に対する区間であり、学習seed間のばらつきは含まない。

## 行動診断と解釈

Heuristic×3相手で、候補共有型は平均で追加開拓地0.70軒・都市0.81軒を建設した。MLPはそれぞれ0.18軒・0.41軒。混合相手でも候補共有型は0.75軒・1.04軒、MLPは0.24軒・0.47軒。初期配置を揃えた場合、候補共有型は通常ターンの建築までつなげられている。

前回の「候補共有＋初期開拓地教師あり」モデルは、初期生産pipsが20.59でもHeuristic×3相手で勝率2%、平均VP5.27だった。今回の固定初期配置は20.54 pipsだが、資源種類数3.95（前回3.78）で、木かレンガが欠ける率は41%（前回57%）。また前回は初期道路をPPOが選び、今回は既存Heuristicが選んだ。さらに、学習中にPPOが初期配置へstepを使わない点も違う。したがって**「初期配置の質だけ」か「学習機会・分布」か、あるいは両方かはまだ切り分けられない**。一方、通常ターンの候補共有Headが全く機能していないという仮説には反証が得られた。

## 次の判断

候補共有方式は維持し、GNNや報酬変更はまだ行わない。まず別の学習seedでも固定初期配置の優位が再現するかを確認する。その後、開拓地と道路の初期配置を別々にHeuristicへ委ねる小さなアブレーションで、配置品質と通常ターンの学習機会の影響を分ける。長時間学習やUI既定モデルへの切り替えは、この再現確認後に判断する。
