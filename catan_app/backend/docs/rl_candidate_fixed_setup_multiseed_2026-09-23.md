# 候補共有型PPO：固定初期配置の3学習seed追試

## 条件

前回の学習seed `20260923` に、`20260924` と `20260925` を追加した。各seedでMLPと候補共有型を1万stepずつ**新規学習**。初期開拓地・道路は両方式とも既存Heuristicへ固定した。Observation v2、Action Space v1、報酬、PPOパラメータ、学習相手Heuristic×3は共通。評価盤面seed `40001`〜`40100`、Player IDローテーション、Heuristic×3とHeuristic×1+Random×2の2条件も共通。各学習seed・方式・評価条件につき100対局、計1,200対局。初期2開拓地は各方式の対応対局ですべて同一。非法Action・打ち切りは0。

| 学習seed | 評価相手 | MLP 勝率 / 平均VP | 候補共有 勝率 / 平均VP | 候補共有−MLP |
| --- | --- | --- | --- | --- |
| 20260923 | Heuristic×3 | 6% / 5.35 | 23% / 6.73 | +17pt / +1.38 |
| 20260924 | Heuristic×3 | 10% / 5.29 | 12% / 6.50 | +2pt / +1.21 |
| 20260925 | Heuristic×3 | 4% / 5.68 | 2% / 4.43 | −2pt / −1.25 |
| 20260923 | Heuristic×1 + Random×2 | 13% / 5.83 | 39% / 7.37 | +26pt / +1.54 |
| 20260924 | Heuristic×1 + Random×2 | 13% / 5.48 | 26% / 7.25 | +13pt / +1.77 |
| 20260925 | Heuristic×1 + Random×2 | 19% / 6.56 | 7% / 5.71 | −12pt / −0.85 |

**結論：候補共有型の安定した優位は未確認。** 2学習seedでは平均VPが改善したが、3つ目では逆転した。1つの学習seed・評価盤面だけから得たbootstrap区間は、この学習seed間の変動を表さない。3学習seedしかないため、単純平均を性能保証のように扱わない。

## 崩れたモデルの追加診断

学習seed `20260925` の候補共有型は、Heuristic×3相手100対局で有料道路建設が平均0回、通常の追加開拓地も0回だった。比較用に、学習seed `20260923` と同じ評価盤面の先頭20対局で方策の合法手上の確率を記録した。

| 候補共有モデル | 有料道路が合法な判断回数 | 道路選択回数 | 合法道路全体への平均確率質量 | 1判断あたりの平均合法道路数 |
| --- | ---: | ---: | ---: | ---: |
| seed 20260923 | 121 | 71 | 68.4% | 6.21 |
| seed 20260925 | 307 | 0 | 43.5% | 5.57 |

弱いモデルでも道路はAction Mask上で合法だった。合計確率質量が43.5%あっても、複数の道路候補に分散すると各道路IDの確率は低くなる。決定論的なargmax評価では、他の単一Action（手番終了など）が勝ち続ける可能性がある。実際、この307判断のうち手番終了が190回だった。ただしこれだけで学習の失敗原因がHead設計だとは断定できず、価値推定・探索・短い学習長も候補に残る。

同じ弱い保存モデルを再学習せず、方策seed `20260923` で**確率的に**Actionを標本抽出した先頭20対局も確認した。有料道路を建てられる192判断のうち93回（48.4%）道路を選び、平均で道路4.65本・追加開拓地0.40軒・都市0.75軒を建てた。決定論的な先頭20対局では有料道路0本・追加開拓地0軒・都市0.55軒。平均VPは3.85から5.70へ上がったが、どちらも勝利0件であり、20対局だけで総合成績改善とは言えない。確率的選択で道路が出ることから、**合法Action生成ではなく、確率の各候補への分散とargmax選択の相互作用**が少なくとも直接の症状である。

## 次の実験判断

初期配置を開拓地／道路に分ける前に、この通常ターンの崩れを切り分ける。まず方策の確率質量と決定論的選択の乖離を再現可能な指標として維持し、同じ保存モデルの確率的評価とチェックポイント比較を行う。評価方法を変える場合は、既存の決定論的評価と混同しない。その後、学習seedを増やすか、候補ごとの採点・Action種別間の校正を小さく比較する。GNN、報酬変更、長期学習、UI既定モデル化はまだ行わない。
