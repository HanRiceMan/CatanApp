# 候補共有型PPO：道路選択のチェックポイント診断

## 方法

固定初期配置で学習した候補共有型の2学習seed（`20260923` と `20260925`）について、保存済み5,000stepと10,000stepのチェックポイントを比較した。評価盤面seed `40001`〜`40020`、Heuristic×3、Player IDローテーション、決定論的Action選択。新たな学習やゲームルール変更はない。

まず各チェックポイントを別々に20対局させた。次に5,000stepモデルが実際に訪れた局面・合法Action Maskを**そのまま**10,000stepモデルへ入力し、反実仮想のargmax行動と行動種別ごとの確率質量を記録した。この同一局面比較では10,000step側のActionを実行しないため、勝率の比較ではなく方策の変化を測る。

## 各チェックポイントの対局

| 学習seed | step | 有料道路が合法な判断 | 道路選択 | 平均VP | 平均有料道路 / 追加開拓地 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 20260923 | 5,000 | 165 | 0 | 3.45 | 0 / 0 |
| 20260923 | 10,000 | 124 | 71 | 6.40 | 3.55 / 0.50 |
| 20260925 | 5,000 | 192 | 146 | 5.00 | 7.30 / 0.20 |
| 20260925 | 10,000 | 323 | 0 | 3.95 | 0 / 0 |

20対局の勝率はseed `20260923` の10,000stepで10%、他の3条件は0%。小標本なので勝率を主結論としない。非法Action・打ち切りは全条件0。

## 同じ局面への入力で確かめた変化

| 学習seed | 5,000stepが訪れた道路合法局面 | 5,000stepの道路argmax | 同じ局面での10,000step道路argmax | 道路全体の平均確率質量（5k→10k） | 手番終了の平均確率質量（5k→10k） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 20260923 | 165 | 0% | 35.2%（58回） | 48.2%→57.7% | 19.8%→11.0% |
| 20260925 | 192 | 76.0%（146回） | 0% | 76.0%→40.8% | 7.1%→24.4% |

弱いseed `20260925` では、同じ192局面に対する10,000step方策のargmaxは手番終了121回、開拓地34回、貿易18回などで道路0回だった。道路ActionはMaskに残っており、確率質量も約41%あるが、複数候補に分散している。5,000→10,000stepの学習更新で行動種別間の相対的な優先順位が大きく変化したことが、局面分布の違いを除いても確認できた。良いseedでは逆方向に変化した。

これは**症状の位置を特定した結果**であり、原因が候補Headの構造だけにある証明ではない。報酬・価値推定・学習率・探索・短い学習長、確率分布と決定論的argmaxの関係を引き続き区別する必要がある。単純に道路へ報酬を足したり、UIに弱いモデルを載せたりはしない。

## 次の小さな実験

既存チェックポイントの確率的選択を、十分な同一評価盤面数で測る。その結果でもseed間の差が大きければ、Action種別の確率校正や安定化を**評価専用の選択方式**として小さく比較し、実学習の変更はその後に判断する。比較時は「決定論的argmax」「確率的抽出」「補正あり」を明確に分け、学習seed・評価seedを揃える。GNNや長期学習へはまだ進まない。

## 保存物

- `experiments/candidate_road_checkpoint_{5k,10k}_s{20260923,20260925}/trace.json`：各チェックポイントの20対局と行動種別確率。
- `experiments/candidate_road_same_state_s{20260923,20260925}/trace.json`：5,000stepが訪れた局面での同一状態比較。
- `app/rl/inspect_policy.py`：任意の保存済みチェックポイントと同一局面比較を追加。通常AI・UIの動作は変更していない。
