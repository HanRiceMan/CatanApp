# 候補共有型PPO：決定論的選択と確率的選択の100対局比較

## 実験条件

固定初期配置で学習した候補共有型の学習seed `20260923` と `20260925`、それぞれの5,000/10,000step保存チェックポイントを再学習せず使用した。各チェックポイントにつき「合法Action中の最大確率を選ぶ」（決定論的）と「マスク後の方策分布から標本抽出する」（確率的）を比較した。

評価盤面seed `40001`〜`40100`、Player IDローテーション、相手Heuristic×3、初期配置Heuristic固定、Observation v2とAction Space v1は共通。確率的選択の乱数seedは `20260926`。各条件100対局、計800対局。各ペアの初期2開拓地は全対局で同一だった。非法Action・打ち切りは全条件0。

| --- | ---: | --- | --- | ---: |
| 20260923 | 5,000 | 0% / 3.70 / 0.00 / 0.00 | 3% / 5.06 / 6.59 / 0.58 | +1.36 |
| 20260923 | 10,000 | 22% / 6.67 / 4.81 / 0.73 | 10% / 5.87 / 5.58 / 0.64 | −0.80 |
| 20260925 | 5,000 | 8% / 5.34 / 7.61 / 0.27 | 3% / 5.01 / 7.32 / 0.48 | −0.33 |
| 20260925 | 10,000 | 2% / 4.48 / 0.00 / 0.00 | 6% / 5.82 / 5.34 / 0.86 | +1.34 |

道路・追加開拓地は1対局あたり平均建設数。同じ評価盤面・Player ID・席を対応させた平均VP差のbootstrap 95%区間は表の順に `[+0.92,+1.81]`、`[-1.33,-0.29]`、`[-0.72,+0.06]`、`[+0.86,+1.82]`。勝率差は順に+3、−12、−5、+4ポイント。勝率差のbootstrap区間は順に`[0,+7]`、`[-21,-3]`、`[-11,+1]`、`[0,+9]`ポイント。

これらの区間は**この固定されたチェックポイントと確率的方策seedに対する評価盤面変動**であり、学習seedや確率的選択seedを変えた場合の不確実性を含まない。

## 解釈

道路をargmaxで全く選ばなかった2チェックポイントは、確率的抽出では道路を建て、平均VPも大きく改善した。前回の同一局面診断と合わせ、合法Actionの欠落ではなく、候補へ分散した確率とargmaxの相互作用が実際の対局結果にも影響することが確認できた。

ただし、道路を既に選べる10,000step（seed `20260923`）では確率的抽出の勝率・平均VPが下がった。確率的抽出をUIや評価の既定にするのは適切でない。また、弱い10,000step（seed `20260925`）を確率的に動かしても勝率は6%であり、学習済み方策の品質問題も残る。

## 次の判断

現段階では、通常AI・UI・学習器の既定動作を変更しない。次の比較は**評価専用**に限定して、Action種別の確率と個々の候補の確率を分けて選ぶ方式を検討する。例えば「行動種別を選ぶ→その種別内の候補を選ぶ」を小さなオフライン実験とし、全seedで改善するか、道路の過剰建設が起きないかを同じ評価盤面で確認する。単なる道路ボーナスやGNN・報酬変更・長期学習を同時に導入しない。
