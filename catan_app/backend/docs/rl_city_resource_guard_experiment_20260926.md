# 都市資源保護の比較実験（2026-09-26）

## 目的

都市化に使える鉱石・小麦を、4:1銀行交換や発展カードへ使い切ってしまう局面を減らす。
ただし、都市を固定目標にして停滞することや、盗賊などで手札が変わった後も古い計画に固執することは避ける。

## 動的な計画判定

都市と開拓地の候補は保存せず、行動を選ぶ直前に現在の手札・盤面・港・生産力から毎回再計算する。
都市の推定待ち時間、開拓地の推定待ち時間、それぞれの生産価値を比較し、都市が現実的な候補である時だけ保護を検討する。

このため、盗賊や取引で手札が変わり、開拓地より都市が近くなれば都市へ、逆なら開拓地へ切り替わる。
この切り替えは単体テストで再現している。

## 実験1: 発展カードも含む都市資源予約

都市用の鉱石・小麦を割り込む銀行交換と発展カード購入を止めた。

同一100盤面で現行AIと比較した結果:

| 指標 | 現行 | 候補 |
|---|---:|---:|
| 勝率 | 91% | 89% |
| 平均得点 | 9.83 | 9.80 |
| 開拓地 | 2.63 | 2.50 |
| 都市 | 2.64 | 2.78 |
| 発展購入 | 2.03 | 1.68 |

都市は増えたが発展購入と開拓地が減り、勝率も下がったため不採用とした。

## 実験2: 4:1銀行交換だけを制限

発展カードは保護対象から外し、停滞・盗賊解除・最大騎士力の既存判断に任せた。
銀行交換では、現在持っている都市資源のうち都市コスト以内だけを保護する。

例: 鉱石8枚、都市用必要数3枚、4:1交換の場合、最初の交換は許可して鉱石4枚を残す。
2回目は都市用の3枚を割り込むため止める。ただし開拓地の方が明確に早い局面では保護しない。

2組の独立100盤面、合計200局の結果:

| 指標 | 現行 | 候補 |
|---|---:|---:|
| 勝率 | 87.0% | 88.0% |
| 平均得点 | 9.735 | 9.730 |
| 平均順位 | 1.155 | 1.155 |
| 開拓地 | 2.765 | 2.700 |
| 都市 | 2.545 | 2.575 |

都市は0.03増えたが、得点・順位は改善せず、開拓地が0.065減った。
盤面別の有利不利が大きく、総合的な強化とは判断できない。

## 結論

`protect_city_bank_trade_reserve` は実験用の無効設定として残し、本番モデル設定では有効化しない。
最新AIのアプリ上の挙動は変更しない。

次は資源を固定的に予約するのではなく、各候補行動後の「次の1点までの待ち時間」がどれだけ変化するかを直接比較する方が安全である。
