# 建設を中心にする次期方針（2026-09-25）

## 評価の優先順位

最終目標は固定ルールAI3人に対する勝率80%。最大騎士力・最長交易路の取得率を
維持することは採用条件にしない。称号を取らなくても、建設と都市化で早く10点へ
到達できればよい。建設数も単純最大化せず、勝利へつながる生産・拡張・得点として評価する。

1. 未使用盤面での勝率、平均点、平均順位。
2. 初期配置を除く開拓地新設数、都市への昇格数、総拠点数、建物だけの得点。
3. 4拠点目・1都市目・2都市目の到達率と到達した自分手番。
4. 自分の10・20手番終了時点の総拠点数、都市数、生産ピップ。
5. 称号取得・発展購入・道路数は戦い方の説明に使う参考指標。

「開拓地新設2.5個」は初期2個に加えて平均2.5拠点増えたという意味。
都市化は同じ地点の昇格なので、総拠点数は増えず、盤上の開拓地コマは減る。
比較には新設数と都市化数を使い、残った開拓地コマ数だけでは判断しない。
建物得点は残存開拓地数 + 2 × 都市数。

到達時間は到達局のみに限定した平均と到達率を併記する。
10・20手番の数値はその時点の手番終了を観測できた局だけの平均であり、観測局数を
併記する。早期勝利・敗北局を0点として埋めない。生産ピップは盤面の名目生産力で、
盗賊の一時停止や銀行在庫切れを含む実収入ではない。

## 今回検証する変更

4拠点以上では、購入可能な開拓地・都市を称号用道路より先に実行する。
ただしその1本道で最長交易路を獲得して10点に届く場合は勝利を優先する。
これは購入可能な建設の優先順位を比較する第一段階であり、資源待ちの状態で
どの計画を選ぶかまで解決するものではない。

3拠点時の購入可能都市については、前回の独立100局で勝率58%→58%、
開拓地新設2.48→2.51、都市化2.22→2.39だった。
称号率の低下を理由に棄却せず、建設重視の候補基準に含める。

## 続く改善順序

### 1. 次に建てるものを盤面から選ぶ

「4拠点まで開拓、その後都市」という固定境界を段階的に柔軟化する。
各局面で、既存道路に接続した開拓地、良い土地・港へ伸ばす開拓地、都市化を候補にする。
必要資源・現在の手札・資源別生産・交換比率から建設までの待ち時間を比較し、
建設後の生産増、足りない資源の補完、港の交換改善、他者に塞がれる危険も見る。
単なる総ピップではなく、そのプレイヤーの次の建設に役立つかを評価する。

最初は3拠点以上で、接続済み開拓地と都市化の2案だけを比較する小さな実験とする。
道路延伸・港・称号まで一度に変更すると、勝率変化の原因を判断しにくいため順に広げる。
資源待ちの概算は現在のコードにもあるが、平均生産量と端数交換の近似を使うため、
「今すぐ建てられる」の判定には必ず合法Actionと実際の整数枚数の交換を用いる。
勝敗別の初期資源差は仮説を立てる診断であり、それだけで因果関係とは判断しない。

### 2. 建設を遅らせる支出を局面ごとに判断する

道路・発展カード購入の後に、選んだ建設の待ち時間が何手番延びるかを測る。
道路は接続先の土地・港の価値、称号への道は必要本数と取得後の維持見込みを比較する。
発展カードは建設停滞、盗賊の生産停止、手持ち騎士と最大騎士力への距離に応じて選ぶ。
未知のカードや相手の手札内容を判断材料にしない。

称号に近いという理由だけで生産投資を先延ばしにしない一方、低コストで勝利へ
届く称号は選択肢として残す。都市化と称号で使う資源が競合しない場合も評価する。

### 3. 成功した計画判断をGNNへ学習させる

今の改善は学習済みPPOに重ねた計画コードと初期配置フィルタであり、今回GNNの重みを
再学習したわけではない。まず少数の計画候補を同じ状態から比較して判断材料を集める。
現行PPOを基準に、実対局結果が改善する判断を追加学習する。学習・選定・最終評価の
盤面を分離し、既存の良い行動が崩れないよう元方策からの変化を抑える。

## 検証と反映

探索50局で選んだ候補を別の未使用100局で確認し、最後に設定を固定してより広い
未使用盤面で勝率80%を判定する。探索で何度も見た盤面は最終評価に再利用しない。
同じseedとPlayer IDを対応させ、開始席分布も保存する。相手は固定ルールAI3人。

勝率だけ同等で建設・都市化が改善する候補も残す。称号率の低下のみでは棄却しない。
ただし「有意な差が出ない」を「完全に同等」とは扱わず、差の区間を併記する。

前回メッセージで採用と言及した木・レンガ3ピップ、麦1ピップ、2都市目予約は、
2026-09-25の確認時点では実験コードにあり本番configには未反映だった。
また実験の都市待機上限9と本番のデフォルト6が一致していなかった。
今回の比較は全設定をdefinition.jsonへ明記し、本番反映時に同じ設定をロードする。

## 3拠点時の都市・開拓地比較と称号道路延期

未使用50局ずつで追加検証した。

3拠点時に、完成待ち時間で割った生産価値が開拓地以上なら都市を選ぶ案は、
勝率66%→62%、4拠点目14.88→16.06手番、最終都市2.44→2.32。
都市に25%の優位を要求する慎重案も勝率64%、4拠点目15.58手番だった。
早い都市が4拠点目を遅らせ、最終的な都市数も増えないため不採用。
`three_site_city_value_ratio` は既定0で無効。

建設が1ラウンド以内なら称号用道路を延期する案は、開拓地新設2.46→2.58に
増えたが勝率58%→48%。2ラウンド案は開拓地2.60、勝率44%。
追加開拓地約0.1個では称号2点の代替にならなかった。称号取得率を採用条件には
しないが、盤面価値を比較せず一律に称号を捨てる案は不採用。
`title_road_build_wait_threshold` は既定0で無効。

改善構成100局の敗戦34局は、開拓地新設2.20、都市化1.85、総拠点3.94。
勝利66局は開拓地2.80、都市2.94、総拠点4.80だった。
次は称号を一律制限せず、2都市到達後に近い3都市目を取り切る計画を検証する。

## 追加の棄却実験

2都市後に不足1〜2枚の3都市目を予約する案は、50局で都市を平均
0.02〜0.04増やしたが勝敗を1局も変えなかったため保留した。

盤面・席順から現行GNN、Heuristic、pips最大の初期配置方式を選ぶ価値モデルも
試した。160局の勝敗和集合は81%、独立30局では90%だったが、1343次元モデルは
全局で現行を選び、説明可能な69特徴へ圧縮したモデルも独立テストで70%から
66.7%へ悪化した。勝敗を後から見た理論上限を、初期公開情報から安定して予測できず、
本番には入れていない。

初期2拠点へ鉱石1pipを追加要求する案は探索50局で勝率+8pt、都市+0.28だったが、
独立100局では勝率差0、都市-0.05。都市化地点へ不足気味の鉱石・小麦価値を加える
案も探索50局では勝率+6ptだったが、独立100局では+1pt、都市-0.05だった。
どちらも再現しないため既定値は無効のままにした。

現行65k GNN、96k系列、初期配置GNNの土台系列を同じ計画層で比較した。
探索50局の勝敗和集合は76%で目標80%未満。土台系列は探索で74%だったが、独立
100局では現行68%に対して57%、現行敗戦を救ったのは1局だけだったため不採用。

## 5拠点計画の検証と反映

4拠点到達後も、5拠点目まで道路・開拓地費用を一つの計画として予約する案を試した。
購入可能な都市、即時勝利、近い称号、8点以降の1点予約は従来どおり残す。

探索50局（seed 880001〜）では、4拠点基準68%に対し待機6・待機9とも72%。
待機6は開拓地新設2.66→3.16、都市2.52→2.28、平均点8.98→9.16だった。

完全未使用100局（seed 890001〜）の待機6確認結果:

|---|---:|---:|
| 勝率 | 56% | **63%** |
| 平均点 | 8.20 | **8.45** |
| 平均順位 | 1.785 | **1.690** |
| 開拓地新設（初期除外） | 2.30 | **2.71** |
| 都市化 | 2.29 | 2.18 |
| 建物得点（概算） | 6.59 | **6.89** |

対応ありbootstrap 95%区間は、勝率差+7pt [-1,+15]、開拓地+0.41
[+0.26,+0.57]、都市-0.11 [-0.33,+0.10]。都市は僅かに減ったが、開拓地増加が
上回り建物得点・平均点・順位・勝率が同方向に改善した。探索でも同じ方向だったため、
本番計画を5拠点・待機6へ更新した。称号率低下だけでは棄却していない。

本番表示の63%は難しい独立100局での観測値であり、旧表示66%と異なるseed帯なので
単純な絶対比較はできない。同一盤面上では4拠点案より+7ptだった。最終目標80%は未達。
