# 発展カード購入判断のPPO移管（2026-09-27）

## 目的

選択可能な `盗賊PPO移行AI（実験版）` を土台に、次の一領域として発展カードを
買うかどうかだけを計画層からPPOへ移す。道路・開拓地・都市・交渉・盗賊の既存判断は
固定し、同時に複数の計画層を外さない。

## 専用Head

`RobberDevelopmentMigrationMaskablePolicy` を追加した。盗賊PPOの全parameterを移植し、
発展購入Family logitだけを変更できる小さな残差Headをゼロ初期化する。追加直後の
全Action logitは盗賊PPOと完全一致する。補正は購入抑制専用ではなく、停滞・盗賊解除・
最大騎士力争いでは正方向にも学習できる。

教師データは発展カードを購入可能なaction局面だけを保存する。教師が購入した正例と、
購入可能でも道路・建設・交換・手番終了を選んだ負例の両方を含む。

## v5盤面特徴だけの試験

60局学習・15局検証で458件・125件を収集した。検証の教師購入率は27.2%に対し、
元PPOは68.8%であり、計画層が隠していた生PPOの買いすぎを確認した。

- 強度6・KL 1.0: 購入率56.0%、二値一致64.8%
- 強度8・KL 1.0: 購入率51.2%、二値一致68.0%
- 強度6・KL 0.25: 購入率50.4%、二値一致68.8%
- 強度12・KL 0: 購入率32.0%、二値一致72.8%

強度6・KL 0.25版は最初の8局を維持したが、独立40局では対強敵勝率35.0%→27.5%、
平均点7.725→7.000、対ルールAI勝率82.5%→77.5%、平均点9.475→9.350へ悪化した。

## Observation v6

v5の共同ベイズ手札推定と絶対席情報に、発展購入用25特徴を追加した（1,747次元）。

- 購入可能、即時建設可能、同一手番で購入済み
- 拠点数、得点
- 購入前後の建設待ち時間、遅延、許容遅延
- 盗賊で止まる生産pip、最大騎士力までの距離
- 建設停滞・盗賊解除・最大騎士力競争の理由フラグ
- 未公開発展カードの種類別確率と種類別価値、期待価値

最終的な `eligible` 判定は入力しない。盗賊PPO本体には従来のv5部分だけを渡し、追加25
特徴は発展専用Headだけが読む。さらに元PPOの15 Action Family logitも入力し、元PPOが
購入をどの程度強く希望しているかを条件付けた。

60局学習・15局検証、強度12・KLなしでは、検証購入率23.4%に対して候補24.2%、
二値一致83.6%、Family一致71.1%まで改善した。しかし同一8局では対強敵の平均点が
7.625→6.875、対ルールAIが9.375→8.125となった。

教材を240局学習・60局検証へ増やし、2,107件・536件で再学習したが、検証二値一致は
83.2%で改善しなかった。学習一致83.9%とほぼ同じため、単純なデータ不足や過学習では
なく、入力から区別できない局面が残っている。

## 判断

全候補を不採用とし、アプリの盗賊PPOは変更しない。PPO勝敗学習にもまだ進めない。

次はデータ量をさらに増やすのではなく、建設計画を今すぐ一歩進められるかを表す入力を
追加する。少なくとも、目標道路の即時建設、有効な銀行交換、接続済み開拓候補、都市の
即時建設を区別する。教師購入率を合わせるだけでなく、未使用局面の二値一致90%以上を
満たしてから対局評価へ進む。
