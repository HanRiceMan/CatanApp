# PPO改善前の実装監査・混合対戦診断

今回は長時間学習を再開せず、既存2モデルを監査・評価した。先に提案した初期配置pipsの補助報酬は保留する。まず相手の難易度を変更する比較実験を優先する。

## 既存実装の確認

| 項目 | 確認結果 |
| --- | --- |
| Observation | v1、float32、1,343次元。カテゴリはone-hot、枚数等は0〜1に正規化 |
| 非公開情報 | 相手の資源内訳・未使用発展カード内訳・実VPはPolicyへ渡さない |
| 盤面の接続 | 固定ID順のタイル・交差点・辺。接続行列やGraph Encoderは未使用 |
| Action | v1、377個。相手間交渉はRL環境のみ無効、破棄は決定的な半数破棄 |
| 学習時Mask | CatanEnv.action_masks → MaskablePPOのrollout収集・更新に渡される |
| 推論時Mask | PPOAgent.select_actionがpredictに明示的に渡し、結果も検証 |
| Reward | 勝利+1、敗北−1、実VP差分×0.05。すでにVP補助報酬あり |
| 通常ゲーム | API・UI・ゲームルール・既存Heuristicのコードは今回変更なし |

学習バッファの選択Actionが保存Mask内であること、推論が合法手を返すこと、対局中の複数局面のMask候補を既存ルールへ適用できることをテストした。診断全768試合でも非合法Actionと打ち切りは0件、Observationは全ステップで有限・0〜1だった。

終局時、勝者のObservation実VPに勝利点カードが二重加算されていたため修正した。通常対局中のObservationやRewardの実VP計算はこの不具合の対象外。過去に報告した評価得点も別の正しい計算を使っていた。入力次元やAction IDは変更していない。

ターン数の正規化は200手番で飽和する。100万step PPO対Random×3では48試合中26試合が200手番以上となった。値の範囲違反ではないが長期戦の区別が失われる。今回は入力仕様を維持し、将来のObservation v2候補として記録する。

## 診断条件と保存物

- Experiment ID: `diagnostic_v2_20260922`
- 各条件48試合、盤面seed 20001〜20048。4Agent×4相手構成=768試合。
- 学習者IDをP1〜P4で回す（各12試合）。混合相手の割当も回す。実際の1〜4番手は通常の順番決めダイスで決め、Player IDと別に記録する。
- PPOはdeterministic推論。Reward・重み・盤面ルールは変更なし。
- **今回の公平比較では全員のダイスをゲームRNGに任せ、破棄を同じ決定的処理に揃えた。** 旧比較は学習者側だけにこの変換があり、相手Heuristicは独自のダイス指定・破棄だった。今回と旧比較の数値は区別する。既存環境のデフォルトは旧動作を維持し、診断時に明示的に切り替える。
- 同seedでもActionが異なれば乱数消費順や試合の長さは変わる。完全に同一のダイス列を保証する比較ではない。
- `experiments/diagnostic_v2_20260922/definition.json`: 条件、seed列、ソースとモデルのSHA256。
- 同フォルダの`audit.json`: 実パラメータ、元の学習config、依存バージョン、TensorBoard要約。
- 同フォルダのAgent別JSON: 各Episodeと集計。`summary.json`: 全16条件の集計。
- 指標は評価専用。相手の実VPを含む順位分析結果をPolicyや通常UIへ渡さない。

順位は公式ルールの追加ではなく分析用。勝者を1位、残りを実VP順で並べ、同点は平均順位とする。2位枠は同点者で等分する。打ち切りは勝率の分母に含め、順位集計から除外する。称号取得率は終局時の所持だけでなく、試合中に一度でも取得した割合。

## 混合対戦結果

H=Heuristic、R=Random。各セルは「勝率 / 平均VP」。

| 学習者 | R×3 | H×1 + R×2 | H×2 + R×1 | H×3 |
| --- | --- | --- | --- | --- |
| Random | 25.0% / 5.79 | 2.1% / 3.35 | 0% / 3.29 | 0% / 2.94 |
| Heuristic | 100% / 10.06 | 50.0% / 7.92 | 43.8% / 7.83 | 22.9% / 6.56 |
| PPO 30万 | 60.4% / 9.02 | 16.7% / 6.10 | 12.5% / 5.98 | 4.2% / 6.04 |
| PPO 100万 | 58.3% / 8.44 | 10.4% / 5.81 | 10.4% / 5.83 | 6.3% / 5.65 |

H×3での平均順位は30万が2.99位、100万が2.97位。勝率・平均VP・順位を合わせても、継続学習による明確な改善は確認できない。48試合中2勝と3勝の差であり、モデルの優劣を確定できない。

H×1+R×2での2位率は30万63.5%、100万64.9%（同点の2位枠は等分）。Randomには勝ちやすいが、Heuristicが1人いるだけでも先に10点へ到達されやすい。

H×4の48試合では勝者ID P1〜P4は15/15/9/9、実際の1〜4番手では15/9/9/15。偏りの有無を判断するには少ない。特定Player IDの強さや1番手有利を断定せず、将来も両方を分けて記録する。

PPOには発展カード・最大騎士力へ寄った傾向がある。今回の全PPO評価で、合法な開拓地/都市建築が残っている状態でEndTurnを選んだ回数は0。単純な「建築ボタンを押せるのに終わる」よりも、生産・交易・道路展開を通して建築可能な局面を作れていない可能性を優先して調べる。個々の道路が無意味だった、港を理解していない、とまではこの集計で断定しない。

旧レポートの汎用イベント平均では0件を分母から除外していた箇所を訂正した。現在のAction別集計は0件の試合も含む。旧buildイベントは発展カード購入を含むため、純粋な建築回数として扱わない。

## 探索に関する診断

学習ログのentropy_lossの絶対値は、30万runの序盤100更新平均0.435から終盤0.073へ低下。100万runでは序盤0.071、終盤0.087だった。300k→1Mで単調に探索が消失したという根拠にはならない。

各モデル10対局（同じseed 20001〜20010、H×3）で、複数合法手がある局面だけの確率を記録した。

| 指標 | PPO 30万 | PPO 100万 |
| --- | ---: | ---: |
| 初期配置の正規化entropy平均 | 0.333 | 0.286 |
| 通常行動の正規化entropy平均 | 0.047 | 0.193 |
| 通常行動で最大確率99%以上の割合 | 74.5% | 49.5% |

正規化entropyは0が一択に集中、1が合法手内で一様。訪れる局面がモデル間で違うため、同一局面での比較ではない。初期配置は集中傾向だが、100万版の通常行動は30万版より分布が広い。ent_coefを増やせば改善するとはまだ判断しない。

`experiments/policy_trace_300k_20260922/trace.json`と`policy_trace_1m_20260922/trace.json`に、上位5手の確率、選択Action、本人の資源、手番、フェーズを保存した。これは20対局分の機械的な追跡であり、人間がUIで20対局を観戦したという意味ではない。確率のUI表示は未実装。

## 次の実験方針

1. 初期配置の補助報酬は保留。次は同じ30万checkpointから、対照群H×3と実験群H×1+R×2へそれぞれ追加10万step学習する比較を第一候補とする。変えるのは相手構成。報酬・ネットワーク・gamma・ent_coefは揃える。混合相手の配置を偏らせない設定を用意する。
2. 評価は今回の公平比較経路を両群で共通使用し、調整に未使用の盤面200試合、Player ID回転、4相手構成で実施する。Random相手だけ改善してH×3で悪化するなら採用しない。弱い相手への過適応も確認する。
3. 有望なら学習seedを最低3種類へ増やす。評価seedを増やすことと、学習seedの反復は別である。最終評価用の盤面はモデル選択に使用しない。
4. 必要なら初期配置Heuristic固定を**学習条件として**比較する。過去に実施したのは推論時だけの置換診断で、固定初期配置で学習し直した実験ではない。通常ゲームと初期配置の学習を切り分けられる。
5. その結果を受けてgamma 0.995などを単独比較する。再開時のパラメータ反映を先に実装・検証する。探索係数・報酬・ネットワークを同時には変えない。

今回、追加10万step学習はまだ開始していない。MLP-PPOの診断を続け、GNN・LSTM・Self-play・Multi-Agentは後段とする。盤面の接続特徴、道路の到達先、港と生産の相性は今後の診断候補。
