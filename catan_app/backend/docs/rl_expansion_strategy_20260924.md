# 盤面拡張戦略の診断とGNN実験（2026-09-24）

## 人間対戦からの問題提起

`ppo_gnn_board_65k_s03_exp_v003` は、人間との対戦で道路・発展カードへ偏り、
追加開拓地が少ないため終盤に5〜6点で停滞した。道路も港・不足資源・高確率地点を
目標にしているように見えない、という観察が得られた。

## 50局の定量診断

評価条件はHeuristic 3人、座席回転、seed 230001〜230050。通常ルールで評価した。

| 指標 | 1局平均 |
| --- | ---: |
| 得点 | 7.10 |
| 追加開拓地 | 1.16 |
| 有料道路 | 8.16 |
| 全道路（無料含む） | 8.96 |
| 発展カード購入 | 4.84 |
| 接続済み開拓地候補が見える判断 | 35.92 |
| そのうち資源不足 | 34.50 |
| 接続済み候補がある状態で発展購入 | 2.58 |
| 接続済み候補がある状態で道路建設 | 5.26 |
| 新しい開拓地候補を開いた道路 | 4.96 |
| 直後の候補を開かなかった道路 | 4.00 |

開拓地が購入可能な局面では、1.16回中1.16回とも開拓地を選んでいた。
問題は「購入可能なのに無視する」ことではなく、候補が見えている判断の96%で資源が
不足し、その途中で道路・発展カードへ資源を使うため、購入可能局面がほとんど生じない
ことだった。

道路の44.6%は直後に新しい開拓地候補を開かなかった。新しく開いた候補の平均pipは
4.23、実際に建てた追加開拓地は平均5.24pip・1.60資源種だった。人間が指摘した
「道路の目的が弱い」「資源補完が弱い」を数値でも確認した。

## 追加した診断

- 接続済み開拓地候補の有無と資源不足
- 候補がある間の道路・発展購入・手番終了
- 道路が新しい建設候補を開いたか
- 道路端点と新規候補の生産pip
- 港へ接する道路
- 追加開拓地のpip、資源種類、未生産資源の補完、港取得と港相性

これらは評価専用で、Observationや報酬には混ぜていない。

## 拡張カリキュラム

通常UI・ゲームルールは変更せず、学習環境だけに次の任意設定を追加した。

1. 3拠点目を建てるまで発展カード購入を学習Maskから隠す。
2. 接続済み開拓地候補がある間は、無料道路を除く追加道路を学習Maskから隠す。
3. 評価時は制限を外し、必ず通常ルールで測る。

現行モデルを直接1024step継続学習した短期確認では、20局の追加開拓地が
1.45から1.20へ下がった。制限だけでは既存の強い方策を短期間で修正できない。

## 拡張戦略GNN残差

現行GNNへ次の公開情報を明示する残差方策を追加した。

- 交差点の資源別pip
- 自分の資源在庫
- 自分の資源別生産力
- 港の種類・比率と港に接する交差点
- 道路両端と接続先
- 開拓地・都市数

既存の377 Action、Family分布、Action Mask、Observation v2は維持する。
移植直後は新しい最終層を0初期化し、現行モデルの全Action logitと完全一致する。

1024stepの短期確認では、学習率3e-5のKLが約`1.8e-8`、3e-4でも約`1.1e-6`
で、決定的行動はほぼ変化しなかった。長時間学習へ進む前に、新残差を安全に動かす
初期化が必要である。

## 次の実験

ルールAIの模倣は過去に発展カード使用を壊したため使わない。現行PPOの行動分布を教師に
しつつ、カリキュラムで隠した道路・発展購入だけを除いて再正規化した目標分布へ、
拡張残差をKL投影する。その後、制限付きPPO、最後に通常ルールPPOへ段階的に戻す。

採用判定は勝率だけでなく、追加開拓地、道路の新規候補開通率、開拓地pip・資源補完、
平均得点・平均順位を3seedで比較する。現時点の実験モデルはUIへ登録しない。

## 現行PPOを教師にした目標分布事前調整（s04）

ルールAIは教師に使わず、`ppo_gnn_board_65k_s03_exp_v003` が通常ルールで出す
377 Actionの確率分布を教師にした。各局面で、次の行動だけを取り除いて再正規化した
条件付き分布へ、新しい拡張GNN残差をKL投影した。

- 開拓地を**今すぐ建設可能**な局面の有料道路
- 拠点が3未満で、開拓地または都市を**今すぐ建設可能**な局面の発展カード購入

候補地が見えていても資源不足なら道路は残す。開拓地・都市を作れない停滞局面では、
騎士や勝利点を狙う発展カード購入を残す。このため、通常UIのルールやAction Maskは
変更しない。

80局を学習、20局を検証、未使用20局をテストに使用した。新規の拡張残差103,974
パラメータだけを更新し、既存Actor・Criticを含む815,381パラメータは固定した。
制限対象局面は学習101、検証23、テスト27件だったため、通常局面を保つために残しつつ
対象局面のKLを8倍重くした。

| 指標 | 初期PPO | 事前調整後 |
| --- | ---: | ---: |
| 検証・重み付きKL | 0.000587 | 0.000536 |
| 未使用テスト・通常KL | 4.52e-5 | 4.48e-5 |
| 未使用テスト・目標行動一致率 | 1.000 | 0.998 |
| 未使用テスト・制限局面の目標行動一致率 | 1.000 | 0.963 |

保存物は `experiments/expansion_target_pretrain_s04_20260924/`。これは確率分布の
事前調整だけを検証した段階であり、対戦力の改善はまだ示していない。次にこの残差を
制限付きPPO、続いて通常ルールPPOで評価し、道路の新規候補開通率・追加開拓地・勝率を
別途確認する。

## 目標分布v2と通常ルール対戦評価

道路は「今すぐ開拓地を建てられる時だけ止める」から一段進め、各合法道路を盤面上で
1手だけ試し、新しい合法開拓地候補を開く道路がある時は、候補を開かない道路を目標分布
から除いた。候補を開く道路が1本もない時は、港・最長交易路・2本先を狙う余地として
全道路を残した。

3拠点目より前の発展購入は原則として除くが、次の場合は例外として残した。

- 自分の生産地に盗賊がいる
- 既に騎士を2枚以上使い、最大騎士力を狙える
- 48ターン以降も開拓地・都市を建てられず停滞している

80局学習、20局検証、20局テストの事前調整では、未使用テストのKLが
`0.310064`から`0.152582`へ下がった。保存物は
`experiments/expansion_target_v2_s01_20260924/`。

同じ40盤面（seed 272001〜272040）で、現行PPO、v2事前調整直後、制限付き1024stepと
通常1024stepを行った最終モデルを比較した。

| 指標 | 現行PPO | v2事前調整直後 | PPO最終 |
| --- | ---: | ---: | ---: |
| 勝率 | 35.0% | 25.0% | 35.0% |
| 平均点 | 7.325 | 6.875 | 7.450 |
| 追加開拓地 | 1.100 | 1.250 | 1.225 |
| 有料道路 | 6.200 | 6.450 | 6.050 |
| 発展購入 | 5.425 | 4.450 | 5.325 |
| 3拠点目前の発展購入 | 3.850 | 2.750 | 3.775 |
| 道路の開拓候補到達率 | 51.72% | 56.29% | 53.85% |

最終モデルは勝率と平均点を保ち、道路・開拓地は小幅に改善したが、通常PPOへ戻すと
早期発展購入がほぼ元へ戻った。UIモデルへは昇格していない。

## PPO後の方針忘却を抑える実験

### 局面KL再投影

各PPO rollout後に固定局面へKL再投影する方式を試した。学習局面のKLは下がったが、
別seedの検証局面は悪化し、安全装置により更新は不採用となった。少数局面への過学習が
起きやすいため、この方式は採用しない。

### 事前調整パラメータへの近接anchor

各PPO rollout後、新しい拡張残差だけを事前調整済みパラメータへ一定割合戻した。
40局・同一学習seedでanchorなしと比較した。

| 指標 | anchorなし | 15% anchor | 3% anchor |
| --- | ---: | ---: | ---: |
| 勝率 | 35.0% | 20.0% | 35.0% |
| 平均点 | 7.450 | 6.825 | 7.250 |
| 追加開拓地 | 1.225 | 1.200 | 1.175 |
| 3拠点目前の発展購入 | 3.775 | 3.175 | 3.750 |
| 道路の開拓候補到達率 | 53.85% | 56.16% | 56.03% |
| 候補を開かない道路 | 3.300 | 3.025 | 3.100 |

15%は方針を保つ代わりに対戦力を落とした。3%は勝率を保って道路を改善したが、
早期発展と追加開拓地は改善不足で、平均点も0.20低い。どちらもUIへ昇格しない。

## 合法手を残した戦略penalty

診断上、最終モデルは開拓地を建てられる局面では平均1.225回中1.225回すべて建てていた。
一方、接続済み候補がある判断34.575回のうち33.275回は資源不足だった。根本問題は
建設可能時の選択ではなく、そこまでに開拓地用資源を消費することと判断した。

そこで通常の合法手を隠さず、v2の例外条件に該当しない早期発展へ`-0.03`、目的の弱い
道路へ`-0.02`の学習専用報酬を追加した。通常UIと通常評価の報酬は変更していない。
4096stepのpenalty学習と1024stepの通常復帰を行ったが、別の同一40盤面内比較では
事前調整直後から最終まで、勝率22.5%→22.5%、平均点6.50→6.45、追加開拓地
1.225→1.15、早期発展1.95→2.625だった。短期間・弱いpenaltyでは修正不足のため、
これもUIへ昇格しない。

## 現時点の結論と次の実装候補

後処理のanchorは「戦略保持」と「勝率保持」が競合し、数千stepの小さな報酬だけでは
65,360step学習済み方策を十分に変えられなかった。次はActionを隠す後処理ではなく、
PPOの各更新に次の補助損失を同時に加える方法を優先する。

1. 例外外の早期発展確率を直接下げる分類損失
2. 新しい開拓候補を開く道路がある時、その道路群へ確率を寄せる損失
3. PPO lossと補助lossの比率を小さく固定し、勝率・平均点を主目的のまま保つ

補助係数は複数候補を同じ盤面・複数学習seedで比較し、勝率だけでなく早期発展、追加
開拓地、道路到達率が同時に改善したモデルだけをUI候補とする。

## 開拓地目標を先に決める計画器

人間の方針を次のように整理し、`expansion_planner.py`へ決定論的な計画器を追加した。

1. 建物の距離ルールを満たす全交差点について、自分の道路網からの追加道路数を求める。
2. 生産pip、不足資源の補完、港との相性を地点価値として計算する。
3. 地点価値から追加道路の木・レンガと完成の遅れを差し引く。
4. 接続済み候補があれば、資源不足でもそこへ建てるために待つのを基本とする。
5. 道路費用込みでも遠方候補が十分に上なら、その最短経路の最初の道路だけを推奨する。
6. 開拓地・都市の不足資源を現在の生産と港交換で得る概算が6ラウンド以上なら、
   発展カードによる打開を許す。盗賊、最大騎士力、8点以上も例外とする。

計画器は3本先までを対象とし、相手の道路を通らず、相手の建物で道路網が分断される
ルールも経路計算へ反映する。通常UIの合法手には使用せず、教師分布・学習環境・評価診断
だけで使用する。

## 現行AIの計画診断

20局の最初の診断では、1局平均で次を確認した。

| 指標 | 現行AI |
| --- | ---: |
| 有料道路 | 8.50 |
| 計画器が開拓地を待つ場面の道路 | 5.25 |
| 建設が近い場面の発展購入 | 4.55 |
| 建設が遠い停滞中の発展購入 | 0.25 |

現行AIの道路と発展購入の多くが、計画器の「待つ」「建設が近い」という判定中に起きて
おり、人間対戦の所感と同じ問題を別の盤面でも確認した。

## 強制目標v3の棄却

計画外行動の確率を0にする最初の目標分布は強すぎた。同じ40盤面で事前調整直後の
道路が0.20本、追加開拓地が0.225、勝率12.5%、平均点5.60となった。開拓地を待つ
考え方を「道路禁止」として学習すると、新しい候補へ到達できなくなるため棄却した。

## 軟らかい計画目標v4

現行PPOの確率分布を基準にし、次の倍率だけを掛けて再正規化した。

- 接続済み候補を待つ時の道路: 0.25
- 選んだ目標への最短経路にない道路: 0.20
- 建設まで6ラウンド未満の発展購入: 0.35
- 推奨道路、停滞中の発展、盗賊・最大騎士力・終盤の例外: 1.00

対象行動を0にしないため、現行PPOの例外判断を残せる。80局学習、20局検証、20局テスト
では、未使用537局面のKLが`0.05852`から`0.01540`へ下がり、制限対象の最頻行動一致率は
60.6%から90.4%、全体では85.5%から94.0%になった。
