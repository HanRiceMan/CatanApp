# 独立seedでの初期配置実験の再現

## 目的と条件

前回は2本の継続学習モデルが同じ30万stepチェックポイントを共有していた。今回は初めから独立したseed `20261001`、`20261002` でそれぞれ30万stepまで学習し、各チェックポイントから同じ継続seed（`20261011`、`20261012`）で次の2枝を40万stepまで学習した。

- **通常配置**: 初期配置もPPOが選ぶ。
- **Heuristic配置**: 初期開拓地・道だけ既存Heuristicが選び、通常ターンはPPOが選ぶ。

ネットワーク、報酬、PPO設定、盤面ルール、H×3の学習相手は固定した。設定は各 `models/ppo_independent_*/config.json` に保存されている。比較に使った30万stepチェックポイントも各モデルフォルダに保存した。学習時の4試合スモーク評価はモデル選択に使わない。

評価は未使用の共通盤面seed `26001`〜`26200`、Player ID回転、各セル200試合。HはHeuristic、RはRandom。`experiments/independent_setup_replication_20260922/` に6モデル×2相手条件＝2,400試合、`experiments/independent_setup_inference_only_20260922/` に通常配置モデルの**評価時だけ**Heuristic配置へ替えた800試合を保存した。全3,200試合で非法Action・打ち切りは0。

## 結果

表の各値は勝率 / 平均VP。順位は1が最良。

| 初期学習seed | 評価相手 | 30万step基点 | 40万step通常配置 | 40万step評価時だけHeuristic配置 | 40万step Heuristic配置で学習 |
| --- | --- | --- | --- | --- | --- |
| 20261001 | H×1 + R×2 | 6.5% / 5.18 | 10.0% / 4.90 | 12.0% / 6.04 | **26.5% / 7.13** |
| 20261002 | H×1 + R×2 | 11.5% / 5.48 | 7.0% / 5.41 | 17.0% / 6.63 | **18.5% / 6.55** |
| 20261001 | H×3 | 3.0% / 5.19 | 2.5% / 4.33 | 7.0% / 5.62 | **8.0% / 6.29** |
| 20261002 | H×3 | 3.5% / 4.98 | 3.0% / 4.96 | **7.5% / 6.08** | 6.0% / 5.98 |

H×3での平均順位は、通常配置がseed順に3.39 / 3.19、Heuristic配置で学習すると2.70 / 2.85。H×1+R×2では2.43 / 2.24から1.92 / 2.02になった。評価時だけ配置を替えた場合も、特に平均VP・順位が改善した。

初期配置の平均pipsはH×3で通常配置15.63 / 15.51、Heuristic配置20.54、H×1+R×2で通常配置17.69 / 17.33、Heuristic配置22.65。pips以外の資源バランスや道路方向も勝敗に影響するため、pipsだけが原因とは断定しない。

## 解釈

独立した2つの初期学習seedでも、Heuristic配置に替えるとH×3の勝率は約3%から6〜8%になり、平均VPと順位も改善した。**現在のPPOにとって初期配置が重要なボトルネック**という診断は、前回より強く支持された。一方、前回の共有チェックポイント由来モデルで得たH×3勝率14%は、この独立実験では再現しなかった。モデル間のばらつきは大きく、14%を安定した実力として扱わない。

「配置を替えて追加学習する」上乗せは不確実。H×3ではseed1が評価時だけの7.0%→学習時からの8.0%、seed2は7.5%→6.0%と逆転する。混合相手でもseed1は大きく改善するが、seed2は勝率差が小さく平均VPはやや下がる。**確実に効いたのは配置そのもの**で、追加10万stepの学習方式の優劣はまだ決められない。同じPPO Action step数でも、配置を委譲すると経験した対局数や状態分布が変わる点にも注意する。

200試合×セルの勝率には標本誤差があり、独立した学習seedも2つだけ。学習対象はP1固定で、評価時にはPlayer IDを回転した。今回の試験でPPOが自力で良い初期配置を学べたとは言えない。

## 次の判断

1. 通常UIの既定AIは変更しない。学習済み各モデルは既存モデル選択機構から指定可能だが、Heuristic配置モデルの利用時はその設定を明示する。
2. 次はPPOが選んだ初期交差点について、pipsに加え資源種類・相互補完・港・初期道路の行き先を調べる。配置を任せる暫定策と、PPO自体に良い配置を学ばせる課題を分けて扱う。
3. 追加学習の上乗せ、gammaや報酬、相手構成の変更を一度に混ぜない。比較するならさらに独立seedを増やし、同じ評価条件で行う。
