# 初期道路の方向改善（2026-09-30）

## 対象となった問題

- 3人の初期道路が同じ交差点へ集まり、最後の1本が全員の先を塞ぐ。
- 相手が先に開拓地を置いた側へ道路を向け、距離ルールのため有効な開拓候補が残らない。
- 港や高生産の交差点へ向かえる開けた方向より、競争・行き止まり側を選ぶ。

## 実装

GNN/PPOが選んだ初期道路を基準にしつつ、各合法方向について、その先へさらに1〜3本道路を伸ばした時に実際に開拓地を置ける交差点を探索する。評価には次を含める。

- 到達候補の生産pipと資源種類数
- 3:1港および2:1港
- 候補までに必要な追加道路数
- 相手開拓地と距離ルールによる候補消滅
- 最初の合流点にある相手道路と、残っている出口数
- 初期配布で公開された木・レンガから見た道路競争の準備状況

GNNの元選択には小さな優先値を残し、評価がほぼ同じ時は学習済み判断を維持する。明確な行き止まり、完全封鎖、競争で不利な方向だけを戦略層が変更する。

## 検証結果

ルールAI3人に対し、同一シードで現行版と改善版を比較した。

| 指標 | 探索50局 現行→改善 | 独立100局 現行→改善 |
|---|---:|---:|
| 勝率 | 80% → 76% | 78% → 77% |
| 平均得点 | 9.30 → 9.36 | 9.20 → 9.15 |
| 平均開拓地 | 2.60 → 2.72 | 2.79 → 2.83 |
| 平均都市 | 2.70 → 2.60 | 2.44 → 2.50 |
| 初期競合道路/局 | 0.54 → 0 | 0.51 → 0 |
| 開拓候補なし道路/局 | 0.14 → 0 | 0.27 → 0 |
| 完全封鎖道路/局 | 0.04 → 0 | 0.09 → 0 |
| 道路先の候補価値 | 7.20 → 9.90 | 5.55 → 9.95 |

独立100局の勝率差は-1ポイント、対応ブートストラップ95%区間は-10〜+8ポイントで、勝率低下を示す差ではない。一方、候補なし・競合・完全封鎖の減少は95%区間でも0をまたがず、意図した方向選択は明確に改善した。

## 診断

アプリ実行時のAI判断ログへ `initial_road` を記録する。選択辺、全候補の評価、競合相手、出口数、到達可能な上位開拓候補を残すため、次回の実戦画像で方向の根拠を再確認できる。
