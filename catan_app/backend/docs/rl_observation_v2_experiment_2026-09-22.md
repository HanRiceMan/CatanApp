# 交差点生産特徴を明示したObservation v2の比較

## 変更点

Observation v1（1343次元）を維持したまま、v2（1667次元）を追加した。v2は54交差点それぞれに、公開盤面から計算する合計pipsと資源5種類別pipsを `0〜1` へ正規化して加える。相手の資源・未使用発展カード・非公開勝利点は追加しない。Action Space、報酬、MLPの層幅、学習相手、盤面ルールは変更していない。ただし入力次元が増えるため、パラメータ数は802,682から968,570に増える。

学習時と推論時にモデルのObservation版を使い分ける。モデルRegistryはv1/v2両方を読み込めるが、サイズ不一致は拒否する。既存モデルを再保存・上書きしていない。v2モデルIDは `ppo_vertex_features_s01_300k`、`ppo_vertex_features_s02_300k`。

## 比較条件

v1対照はゼロから学習済みの `ppo_independent_s01_300k`、`ppo_independent_s02_300k`。v2を同じ初期seed `20261001`、`20261002`、30万step、PPO設定、相手Heuristic×3でゼロから学習した。学習終了時の4試合スモーク評価はモデル選択に使わない。

未使用の共通盤面seed `27001`〜`27200` でPlayer IDを回転し、各モデル200試合×相手2条件を評価した。H=Heuristic、R=Random。対局評価1,600試合で非法Action・打ち切りは0。生データは `experiments/observation_v2_comparison_20260922/`。初期配置の選択確率は `experiments/observation_v2_setup_policy_20260922/`、配置特徴は `experiments/observation_v2_setup_choices_20260922/` に保存した。

## 結果

値は勝率 / 平均VP。平均順位は全4条件でv2が改善していない。

| 初期seed | 評価相手 | v1 | v2 |
| --- | --- | ---: | ---: |
| 20261001 | H×1 + R×2 | 8.0% / 5.35 | 10.5% / 5.57 |
| 20261002 | H×1 + R×2 | 6.5% / 5.57 | 6.0% / 4.66 |
| 20261001 | H×3 | 3.5% / 5.21 | 2.5% / 4.98 |
| 20261002 | H×3 | 5.0% / 5.16 | 2.0% / 4.44 |

H×3の初期合計pipsはseed1でv1 15.58→v2 15.83とほぼ同じ、seed2では15.68→13.26へ低下。1軒目の方策を見ると次の通り。

| 初期seed | 版 | 最多交差点IDへの集中率 | 選択した交差点への平均確率 | 最高pips候補への平均確率 |
| --- | --- | ---: | ---: | ---: |
| 20261001 | v1 | 81.0% | 97.6% | 14.4% |
| 20261001 | v2 | 82.5% | 97.3% | 8.8% |
| 20261002 | v1 | 82.0% | 92.7% | 13.6% |
| 20261002 | v2 | 94.0% | 99.4% | 0.2% |

v2 seed2は港に接する交差点ID 48をほぼ固定で選び、1軒目の平均pipsがv1の8.43から6.28へ下がった。この現象の原因が港情報なのか、固定Action IDや報酬による偶然の収束なのかは未確定。

**結論：今回の単純な特徴追加は採用しない。** 公開情報をAIに明示しても、現在のMLP方策は盤面に応じて交差点を十分に選び分けなかった。1つのseedで混合相手に小幅な改善はあったが、独立seedおよび強い相手3人では再現しない。300k時点の結論であり、追加学習で逆転しないと証明したものではない。ただし現状の結果だけで長期学習へ進む根拠もない。

## 互換性と次の一手

v1モデル2本はv2追加前後に同じ200盤面で再生し、初期開拓地・道路が合計400/400試合で一致した。v1/v2双方をRegistryから読み込める。相手の非公開カードを変えてもv2の入力が変わらないテストを含め、バックエンド全88テストが成功した。通常UIの既定モデルは変更していない。

次は大規模PPO再学習ではなく、**初期配置だけの教師あり診断**が有用。既存Heuristicの合法な開拓地選択を教師として、v2入力を使う現行MLPが未見の盤面でも高pips地点を選べるかを小規模に確認する。これに成功するなら、現在の問題は長期報酬から初期配置へ信号が届きにくいことが主因候補。教師ありでも固定IDへ偏るなら、交差点候補を共通ネットワークで採点する方策構造を検討する。教師ありモデルを通常AIへ自動採用しない。
