# PPO追加10万step：相手構成だけを変えた比較

## 目的と条件

30万step時点の同じ `ppo_heuristic_300k_v001/checkpoint_300000_steps.zip` から2本を再開し、40万stepまで学習した。学習seedは両方 `20260923`。報酬、盤面ルール、ネットワーク、PPOハイパーパラメータ、初期配置を変えていない。再開元モデルのハイパーパラメータと指定値が一致することをコードで検証する。

| モデル | 追加10万stepの相手 |
| --- | --- |
| `ppo_heuristic_control_400k_v001` | Heuristic × 3（対照群） |
| `ppo_mixed_h1r2_400k_v001` | Heuristic × 1 + Random × 2（実験群） |

混合群のHeuristic席は各Episodeのゲームseedで3席を回す。同じseedで同じ割当を再現できる。通常のUI対局・既存Environmentのデフォルト設定は変えていない。

評価は元の30万stepモデルも含む3モデルに対し、相手構成4通りを各200試合、合計2,400試合。盤面seed `22001`〜`22200` はこの追加学習にもモデル内蔵の12試合確認にも使っていない。Player IDを4通りに回し、各モデルで同じ盤面・相手割当順を使用。前回診断と同じ評価専用の確率イベント経路 (`policy_compatible_opponents=True`) を全モデルで使った。これは学習時の対戦相手設定とは異なるが、モデル間の評価条件を揃えるためのもの。非公開情報は評価器の集計にのみ用い、AgentのObservationへ渡していない。

## 結果

各セル200試合。勝率の括弧内は勝利数。順位は小さいほどよい。

| 評価相手 | 30万step 勝率 / VP / 順位 | 対照40万step 勝率 / VP / 順位 | 混合40万step 勝率 / VP / 順位 |
| --- | --- | --- | --- |
| Random × 3 | 58.5% (117) / 8.74 / 1.58 | 56.0% (112) / 8.41 / 1.71 | 61.5% (123) / 8.62 / 1.62 |
| Heuristic × 1 + Random × 2 | 15.0% (30) / 5.96 / 2.15 | 11.5% (23) / 5.87 / 2.20 | 14.0% (28) / 6.10 / 2.08 |
| Heuristic × 2 + Random × 1 | 7.5% (15) / 5.61 / 2.61 | 7.0% (14) / 5.59 / 2.68 | 10.0% (20) / 5.84 / 2.60 |
| Heuristic × 3 | 8.0% (16) / 5.77 / 2.93 | 4.5% (9) / 5.23 / 3.03 | 7.0% (14) / 5.90 / 2.87 |

全条件で打ち切り0、Illegal Action 0。200試合のペアで見た混合群−対照群の勝利数は、Random×3で+11、H1R2で+5、H2R1で+6、H3で+5。H3の5勝差は17件の「片方だけが勝った」盤面の差（混合のみ11件、対照のみ6件）であり、これだけで優位性を確定できない。

H3では混合群の平均VPが対照群より+0.675、元30万stepより+0.130。平均順位は対照群より0.160位良い。開拓地建築は混合群0.57回/試合、対照群0.24回、元モデル0.36回。購入発展カードは混合群4.64枚、対照群4.90枚、元モデル5.36枚。初期配置pipsはそれぞれ16.01、15.66、15.97で近い。混合学習で開拓地展開が増えた可能性はあるが、今回の1学習seed・行動集計だけでは因果関係を断定しない。

## 判断

**混合学習は、同じ30万step起点でHeuristic×3を継続した対照群より、この評価では全4条件の勝率・平均VP・平均順位が良かった。** ただし、最重要のH×3勝率は元30万stepの8.0%を超えず、混合群7.0%。現時点で「新モデルを採用」「相手構成の変更で停滞を解消」とは判断しない。通常UIの使用モデルを勝手に切り替えない。

次の判断材料は、同条件の学習seedを少なくともあと2種類増やすこと。200試合の評価seedを増やすだけでは、学習seed固有の偶然は検証できない。追加seedでも混合群の優位と開拓地増加が再現するなら、H3勝率・VPを主要指標にして採用を検討する。それまではgamma、報酬、初期配置、ネットワーク等を同時変更しない。
