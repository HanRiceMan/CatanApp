# 有料道路の目的ガード（2026-10-02）

## 発端

対人戦 `a1b91943-46b5-437b-a92f-dd17d4e252fb` の47番手で、青（P2）が道路7（交差点4–8）を建設した。

- 交差点4側は紫の道路1・2と衝突済み
- 道路7を建てても青の最長道路長は6のまま
- 青はすでに最長交易路を保持
- 選択中の開拓候補へ近づく道路でもなかった
- 直前に羊3→レンガ1、鉱石3→木1の港交換まで行っていた

同じ青は43番手にも、紫の開拓地で先を塞がれた道路14を建設していた。原因は、開拓計画に有効な候補がない場合に、PPOの元の道路選択をそのまま許可していたことだった。

## 改善内容

通常の有料道路は、次のいずれかを満たす場合だけ許可する。

1. 現在選んでいる開拓候補へ向かう最初の1本である
2. その道路を置いた直後に、自分の最長道路長が実際に増える

元のPPOが条件外の道路を選んだ場合は、合法かつ支払い可能な条件内の道路へ差し替える。該当道路がなければ手番を終了する。

また、木またはレンガを受け取る港交換は、開拓計画の必要資源を減らすか、盤面上に条件内の道路候補があり道路費用を減らす場合だけ許可する。これにより、無目的な道路を建てるためだけの資源交換も止める。

道路建設カードによる無料道路は資源を失わないため、このガードの対象外とした。

## 診断ログ

道路診断の表示も整理した。

- `longest_increased`: この1本で最長道路長が増えたか
- `held_longest_road_before`: 建設前から最長交易路を保持していたか
- `holds_longest_road_after`: 建設後に保持条件を満たすか
- `takes_longest_road_now`: 今回新たに最長交易路を奪うか

以前の `takes_longest_road_now` は、すでに保持中でも `true` になり得たため、道路7の価値を誤解しやすい診断だった。AIの行動決定そのものではなく表示上の問題だが、今回あわせて修正した。
