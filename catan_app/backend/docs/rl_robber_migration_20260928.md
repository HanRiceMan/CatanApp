# 盗賊判断のPPO移管・第1段階（2026-09-28）

## 目的

現行最強AIの計画層から、最初に次の2判断だけをPPOへ移管する。

- 盗賊を置くタイル
- 資源を盗む相手

道路・開拓地・都市・発展カード・交渉など、他の計画層は維持する。

## 実装

### 盗賊専用方策

`RobberBeliefGraphFamilyHierarchicalCandidateMaskablePolicy` を追加した。

- 更新可能なのは盗賊タイル19候補と被害者4候補だけ
- 他354 Actionのlogitは構造上変更できない
- 現行GNN本体と他のAction Headは固定
- ベイズ手札推定そのものはルールベースのまま固定

### Observation v5

v4の1,718次元へ、自分の絶対席を示す4次元one-hotを追加し、1,722次元とした。

従来の相手情報は自分から時計回りの相対順だが、`StealResourceAction`はP1〜P4の
絶対IDである。自分の絶対席がなければ、複数の被害者候補を正しく対応付けられない。

タイルHeadにはGNNのタイル状態と全相手のベイズ推定を、被害者Headには相手別の
ベイズ推定・公開状態・現行PPO logitを入力する。

### 段階的な計画層OFF

`--robber-migration` を追加した。

- 教師データは `robber_move` と `robber_steal` だけ収集
- 候補モデルの `belief_aware_robber` と `opponent_aware_robber` をOFF
- 評価時はPPO自身が盗賊判断を行う
- 現行モデルとアプリ設定は変更しない

### 教師補助報酬

学習環境専用の `robber_teacher_reward` を追加した。教師一致なら正、不一致なら同量の
負報酬を即時に与えられる。通常対局・評価では0であり、ゲームルールには影響しない。

## 事前学習

60局を教師、15局を検証として、393件・93件の盗賊判断を収集した。

小さいbatchで十分に更新した結果:

- 学習一致率: 46.6%
- 未使用検証一致率: 57.0%
- 未使用タイル一致率: 64.2%
- 未使用被害者一致率: 47.5%

初期の19.4%からは大きく改善したが、計画層を置き換えるには不足している。

同一8局評価:

- 現行 vs 強い相手: 4勝、平均8.125点、平均1.875位
- 候補 vs 強い相手: 3勝、平均7.625点、平均2.25位
- 現行 vs ルールAI: 8勝
- 候補 vs ルールAI: 7勝

## PPO対戦学習

### 終局報酬のみ・8,192 step

事前学習版と同じ成績で、明確な改善なし。

### 教師補助報酬 ±0.02・4,096 step

- 未使用一致率は57.0%のまま
- 強い相手3勝、平均7.375点
- ルールAI7勝、平均9.875点

盗賊は1局に数回しかなく、短いPPO更新ではargmaxを変えるほどの学習にならなかった。

## 判断

候補は不採用。現行アプリではベイズ計画層を維持する。

次は単一の正解Actionだけでなく、教師が計算する全合法タイル・全被害者の評価値を
soft targetへ変換し、候補間の順位全体を学習させる。教材の情報密度を上げてから、
補助報酬を段階的に `0.02 → 0.01 → 0` と減衰させる自己対戦へ進む。
