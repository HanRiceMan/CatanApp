# 継続学習seedと初期配置の切り分け

## この実験で変えたもの

前回の相手構成比較では、保存済みPPOの読み込み時にライブラリが保存時seedを再使用し、新しく指定したseedは環境側だけに反映されていた。`train.py` の再開時に `model.set_random_seed(config.seed)` を呼び、Python・NumPy・PyTorch・Gym環境の乱数を揃え直した。小型モデルのテストで、同じseedなら学習後の重みが同一、異なるseedなら異なることを確認した。前回の40万stepモデルは作り直さず、旧実験として保存した。

今回の全継続モデルは、同じ `ppo_heuristic_300k_v001/checkpoint_300000_steps.zip` を起点に40万stepまで学習した。新しい継続seedは `20260924` と `20260925`。ネットワーク、報酬、PPOハイパーパラメータ、盤面ルール、学習対象P1は固定。

## 1. 相手構成を変えた再試行

`experiments/continuation_seed_replication_20260922/` に、未使用の盤面seed `23001`〜`23200` を使う各条件200試合の結果を保存。HはHeuristic、RはRandom。全試合で非法Action・打ち切り0。

| 継続seed | 評価相手 | H×3で学習：勝率 / 平均VP | H×1+R×2で学習：勝率 / 平均VP |
| --- | --- | --- | --- |
| 20260924 | H×1 + R×2 | 20.0% / 6.03 | 13.0% / 5.88 |
| 20260925 | H×1 + R×2 | 8.5% / 5.73 | 14.0% / 6.16 |
| 20260924 | H×3 | 6.5% / 5.57 | 8.0% / 5.21 |
| 20260925 | H×3 | 5.0% / 5.32 | 8.0% / 5.85 |

H×3勝率は混合学習が2seedとも小幅に上回ったが、平均VPは一方で下回る。H×1+R×2では勝率・VPの優劣がseed間で逆転した。**相手構成を変える効果は一貫しない**ため、この変更だけを採用する根拠はまだない。ここで最初から独立した30万stepの学習を増やすより、既に見えている初期配置の問題を切り分けることにした。

## 2. 初期配置の学習条件を切り分けた結果

対照群は上記の `ppo_continuation_s24_h3_400k` / `s25_h3`。実験群は同じ起点・同じ継続seed・H×3相手で学習し、**学習者の初期開拓地と道だけ**既存Heuristicに委譲した `ppo_setup_heuristic_s24_h3_400k` / `s25_h3`。通常ターンはPPOがActionを選び、すべて `apply_action()` を通る。推論時だけ初期配置を替えた対照も別に測定した。

評価は共通の盤面seed `24001`〜`24200`、Player ID回転、各セル200試合。`experiments/setup_training_ablation_20260922/` が学習条件の比較、`experiments/setup_inference_only_20260922/` が推論時だけ替えた比較。全1,600+800試合で非法Action・打ち切り0。

| 継続seed | 評価相手 | 初期配置もPPO | 評価時だけHeuristic配置 | Heuristic配置で学習 | 配置pips：PPO → Heuristic |
| --- | --- | --- | --- | --- | --- |
| 20260924 | H×1 + R×2 | 14.5% / VP 5.66 | 15.5% / VP 6.12 | 17.5% / VP 6.44 | 17.31 → 22.69 |
| 20260925 | H×1 + R×2 | 11.0% / VP 5.79 | 15.0% / VP 6.48 | 20.5% / VP 6.38 | 17.24 → 22.69 |
| 20260924 | H×3 | 7.5% / VP 5.40 | 12.5% / VP 5.95 | 14.0% / VP 6.16 | 15.78 → 20.70 |
| 20260925 | H×3 | 5.5% / VP 5.32 | 12.5% / VP 6.31 | 14.0% / VP 6.29 | 15.31 → 20.70 |

初期配置の出目頻度・勝率・平均VPは2seedとも改善した。H×3の平均勝率は通常配置6.5%、推論時だけHeuristic配置12.5%、Heuristic配置で学習14.0%。**改善の主因は初期配置そのものと考えるのが妥当**で、固定配置での追加学習にも小さな上積みが見られる。ただし、上積みの1.5ポイントは小さく、学習方法の効果を確定できない。H×3の平均VPは通常5.36、推論時だけ6.13、固定配置で学習6.22。初期配置の資源バランス等も影響し得るので、pipsだけが因果要因とは断定しない。

重要な限界：2つの継続seedは同じ30万stepチェックポイントを共有し、初めから独立に学習した2モデルではない。また同じ追加10万stepはPPOが選ぶAction数を揃えるが、初期配置を委譲した群の対局数は変わり得る。評価200試合×各セルにも標本誤差がある。今回の結果は有望なボトルネック診断であり、「14%が安定した最終勝率」とは主張しない。

## 次の段階

1. 初期配置の改善を本採用する前に、独立した初期学習seedでも再現するか検証する。短期なら30万step起点からの別seedを追加できるが、確かな比較には最初の30万stepから独立に学習するモデルが必要。
2. PPOが選んだ初期交差点のpips、資源種類、2つの開拓地の相互補完、道路の展開先を分析する。まずPPOの初期配置を改善対象として扱い、将来はHeuristic委譲なしに同程度の配置を学べるか検証する。
3. PPO本体の探索係数・gamma・報酬・ネットワークは、この実験と同時に変えない。通常UIの既定モデルも自動変更しない。

## 実装・保存物

- `app/rl/train.py`: 継続seedを全乱数源へ適用、初期配置委譲の学習設定とCLI。
- `app/rl/env.py`: 学習者の初期配置だけ既存HeuristicのActionを適用する実験モード。通常モードは不変。
- `app/agents/ppo.py`: そのモードで学習したモデルをUIから選んだときも初期配置だけHeuristicへ委譲。
- `app/rl/diagnose.py`: 推論時だけ配置を替える対照評価。
- `tests/test_rl_phase_2.py`、`tests/test_rl_phase_4.py`: 初期配置委譲、推論経路、同seed再現を検証。
- `models/ppo_continuation_s24_*`、`models/ppo_continuation_s25_*`、`models/ppo_setup_heuristic_s24_*`、`models/ppo_setup_heuristic_s25_*`: モデル・設定・checkpoint。

学習・評価プロセスは全て終了。既存の通常ゲームサーバーは停止・再起動していない。
