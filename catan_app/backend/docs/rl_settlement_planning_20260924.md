# 資源予約付き開拓地計画（2026-09-24）

## 目的

現行PPOは追加開拓地が平均1.1〜1.3程度に留まり、道路や発展カードを減らすだけでは
開拓地が増えなかった。そこで、目標交差点、必要道路、開拓地費用、港・銀行交換を
一つの計画として扱う高レベル計画層を、学習済みPPOの上へ追加した。

## 方針

- 生産pip、不足資源の補完、港価値、道路距離、完成待ち時間から目標交差点を選ぶ
- 目標までの道路費用と開拓地費用を合わせて資源予約する
- 予約済み資源を、目的外道路・都市・発展カードへ使わない
- 余剰資源だけを港・銀行交換へ使い、不足資源を取得する
- 豊作カードを持つ場合は、計画の不足資源を取得する
- 推奨経路の道路と目標開拓地を優先する
- 4拠点到達後、完成予測が9ラウンド超、8点以降は現行PPOへ戻す
- 既存の発展カード使用判断は維持する

相手の手札、発展カード山札順、未来の出目は使わない。自分の手札と公開盤面だけを使う。

同一盤面差は、開拓地+1.20（paired bootstrap 95%区間 +0.97〜+1.44）、
3拠点目達成率+42ポイント（+32〜+52）、発展購入-1.09枚（-1.73〜-0.43）。
勝率は+8ポイント（-3〜+19）、平均点は+0.42（-0.13〜+0.95）で、勝率・平均点の
区間は0をまたぐものの悪化は観測されず、主目的の開拓地増加は強く再現した。

最大騎士力は52%から37%、最長交易路は64%から46%へ下がった。称号より盤面拡張を
優先した結果であり、今後は4拠点到達後の都市・称号戦略を改善余地とする。

## 採用

元のPPOは比較用に維持し、UIへ `開拓計画AI` として別選択肢を追加する。
実行時の識別子は `ppo-plan:ppo_gnn_board_65k_s03_exp_v003`。モデル重みは変更せず、
高レベル計画層だけを重ねるため、生のPPOも引き続き選択できる。
