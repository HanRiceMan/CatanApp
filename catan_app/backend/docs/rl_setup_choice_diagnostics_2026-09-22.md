# PPO初期配置の選択診断

## 方法

独立seedで学習した `ppo_independent_s01_h3_400k`、`ppo_independent_s02_h3_400k` と既存Heuristicを、同じ盤面seed `26001`〜`26200` で比較した。学習者のPlayer IDは4席で回転し、相手3人はHeuristic。初期配置の2軒・2本道までを再生し、通常ターンは実行しない。報酬・学習・UI・ゲームルールは変更していない。

再生したPPOの開拓地IDは、既存の全対局評価 `independent_setup_replication_20260922` の記録と、**各モデル200/200試合で一致**した。生データと要約は `experiments/setup_choice_diagnostics_v2_20260922/` に保存した。診断コードは `app/rl/setup_diagnostics.py`。新規3テストを含むバックエンド全81テストは成功。

## 主な結果

| 指標（200盤面平均） | Heuristic | PPO seed1 | PPO seed2 |
| --- | ---: | ---: | ---: |
| 1軒目pips | 11.43 | 8.54 | 8.54 |
| 2軒目pips | 9.11 | 7.09 | 6.97 |
| 初期2軒の合計pips | 20.54 | 15.63 | 15.51 |
| 選んだ資源種類数 | 4.06 | 3.51 | 3.65 |
| 1軒目が合法候補内で最高pips | 99.5% | 12.0% | 11.0% |
| 2軒目が合法候補内で最高pips | 97.5% | 20.5% | 18.0% |
| 1軒目に使った異なる交差点ID数 | 25 | 3 | 4 |
| 1軒目の最多IDへの集中率 | 7.0% | 76.5%（ID 41） | 75.0%（ID 25） |

PPOは盤面の数字・地形が変わっても、1軒目で特定の**交差点IDを約4分の3の試合で選ぶ**。2軒目もHeuristicの32種類に対し、PPOは6種類・10種類。つまり現在のモデルは、盤面ごとに良い位置を探すより、固定位置に強く偏っている。これは「action IDへの偏り」という観測であり、ニューラルネット構造や報酬のどちらが原因かまでは確定していない。

資源別の生産pipsも全般に低い。特にレンガを全く生産しない初期配置はHeuristicの20%に対してPPO seed1が40%、seed2が36%。ただし「木・レンガ両方あり」の対局が必ず良い結果だったわけではないため、レンガだけを報酬で強制する根拠にはしない。

既存のH×3対局結果400試合を、初期合計pipsで事後的に分けると以下。これは相関であり、座席・他の配置要素・モデル差が混ざるので因果効果ではない。

| --- | ---: | ---: | ---: |
| 13以下 | 90 | 3.88 | 0.0% |
| 14〜17 | 211 | 4.67 | 1.9% |

## 初期道路について

「初期道路からさらに1本道伸ばした先で、距離ルール上空いている交差点の最大pips」を簡易指標として記録した。選択時に合法だった他の初期道路との差、および8組の配置後に残る候補を測定できる。ただし建築費、実際の到達可能性、相手の将来行動、港価値は含まない。

この指標ではPPO道路が一貫してHeuristicより悪いとは言えなかった。PPOの開拓地が弱く、周囲に未使用の高pips地点が残りやすいことも指標に影響する。現時点では**道路改善より開拓地選択の原因調査を優先**する。

## 次の一手

1. まず同じ盤面で、PPOが1軒目に各合法交差点へ割り当てた確率を調べる。数字配置が変わっても固定IDへの確率が高いなら、盤面特徴を方策が十分利用できていない可能性がある。
2. 評価専用に「合法候補から最高pipsを選ぶ」単純Agentを追加し、Heuristicとの差を測る。差が小さければ初期配置の主要改善対象はpips選択、差が大きければ資源バランスや道路方向も重要。
3. 原因が見えた段階で初めて、Observation v2の候補交差点特徴、初期配置専用方策、Heuristic模倣などを**一つずつ**比較する。GNN・報酬変更・大量追加学習はまだ始めない。

この診断では通常UIの既定AI、既存モデル、通常ゲームサーバーを変更していない。
