# 初期配置方策の確率と最高pips基準AIの比較

## 実験条件

既存の独立学習モデル `ppo_independent_s01_h3_400k`、`ppo_independent_s02_h3_400k` とHeuristicを比較した。盤面seedは前回と同じ `26001`〜`26200`、Player IDは4席で回転。初期配置に絞った確率調査では相手はHeuristic×3。対局結果ではHeuristic×3およびHeuristic×1 + Random×2を使用し、相手のダイス・破棄は既存の公平比較設定に揃えた。

新しい評価専用AIは2種類。`greedy_settlement` は初期開拓地を合法候補の最高pipsから選び、道と通常ターンは既存Heuristicに任せる。`greedy_pips` は初期道路も「あと1本道で届く空き候補の最大pips」で選び、通常ターンは同じHeuristic。いずれもGameStateを直接変更せずActionを返す。pips同点時は最小IDを選ぶ。通常UIのAIやゲームルールは変更しない。

保存物：`experiments/setup_policy_probabilities_20260922/`、`experiments/setup_choice_three_way_20260922/`、`experiments/setup_pips_road_ablation_20260922/`。再生したPPOの開拓地選択は初期配置診断の400決定×2モデルと完全一致した。

## PPOの選択確率

| 指標（200盤面平均） | PPO seed1 | PPO seed2 |
| --- | ---: | ---: |
| 1軒目で選択した交差点の確率 | 99.3% | 99.3% |
| 1軒目の正規化entropy（0=一択） | 0.010 | 0.007 |
| 1軒目の最高pips候補への確率合計 | 12.0% | 11.0% |
| 1軒目の最多交差点IDへの集中率 | ID 41に76.5% | ID 25に75.0% |
| 2軒目で選択した交差点の確率 | 88.8% | 92.8% |
| 2軒目の最高pips候補への確率合計 | 19.1% | 17.4% |

前回見つけた固定交差点への偏りは、推論時の偶然ではなく、学習済み方策がほぼ確信している選択だった。現行の盤面エンコードとMLP・固定Action IDの組み合わせで、数字配置の変化を十分に選択へ反映できていない可能性が高い。ただし、観測表現と長期報酬のどちらが主因かはこの実験だけでは分からない。

## 最高pipsだけでどこまで改善するか

各セル200試合。値は勝率 / 平均VP。非法Action・打ち切りは全1,200試合で0。

| 学習者 | H×1 + R×2 | H×3 |
| --- | ---: | ---: |
| 既存Heuristic | 50.5% / 8.00 | 24.0% / 6.83 |
| 開拓地だけ最高pips、道はHeuristic | 49.5% / 7.82 | 17.5% / 6.23 |
| 開拓地・道とも単純pips基準 | 45.0% / 7.81 | 14.5% / 6.25 |
| 参考：PPO seed1 | 10.0% / 4.90 | 2.5% / 4.33 |
| 参考：PPO seed2 | 7.0% / 5.41 | 3.0% / 4.96 |

参考のPPO行は、同じseed・評価条件で実施済みの `independent_setup_replication_20260922` から引用した。Greedyの初期2軒は平均20.59 pipsでHeuristicの20.54 pipsと同等だが、資源種類数は3.69対4.06。H×3で勝率が落ちるため、**最高pipsだけを選べれば初期配置は完成、とは言えない**。pips同点時の資源補完、港、道の方向、相手との競合が関与し得る。道路だけの変更は17.5%→14.5%だが、200試合の標本誤差もあり、その3ポイントを確定的な効果とは扱わない。

## 次の実装候補

最初の改善実験は、Observation v2に各交差点の数字・資源別pipsを明示する方法が適切。Action Space、Reward、MLP、相手、学習step数は固定し、新旧Observationを独立した学習seedで比較する。既存Observation v1モデルとの互換性はバージョンで区別し、通常UIの既定モデルは変更しない。評価では勝率・VPだけでなく、1軒目の最多ID集中率、最高pips候補への確率、資源種類数を合格指標にする。

それでも固定IDへの確信が続くなら、交差点候補を共通の小さなネットワークで採点する構造や、Heuristic模倣による初期化を別実験として検討する。GNN・報酬変更・長時間の追加学習は同時に導入しない。

検証：バックエンド全84テスト成功。学習プロセスは起動していない。
