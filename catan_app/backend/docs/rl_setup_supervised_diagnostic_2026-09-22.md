# 初期開拓地の教師あり診断：固定ID型MLPと共通候補スコア方式

## 目的と範囲

Observation v2を追加してもPPOの初期配置が特定IDに偏ったため、「公開盤面からルールベースAIの初期開拓地を学べるか」を勝敗報酬から切り離して診断した。これは初期配置の開拓地選択のみの教師あり実験であり、通常ターン、初期道路、PPO、UI、モデルRegistryは変更していない。学習モデルを実際のAIとして採用していない。

## 方法

`app.rl.setup_supervised` を追加した。既存の `CatanEnv` で盤面を生成し、`PolicyCompatibleHeuristicAgent` が選んだ合法な初期開拓地を教師ラベルにする。学習者の2軒を各盤面から収集し、他3人は既存Heuristicで進める。盤面seedを区間ごとに完全に分離した。

| 用途 | seed | 盤面数 | 開拓地選択数 |
| --- | --- | ---: | ---: |
| 学習 | 31001–31600 | 600 | 1200 |
| 調整 | 31601–31750 | 150 | 300 |
| 最終評価 | 31751–31900 | 150 | 300 |

両方式とも学習seed 42、Adam `3e-4`、最大40 epoch、batch size 128、調整用損失による早期停止、同じ合法手マスクを使用する。固定ID型MLPはObservation v2全1667要素を入力し、`256→128→54` の層で54交差点を別々に出力する。共通候補スコア方式は、候補ごとに公開情報から計算した資源別pips、合計pips、既存自拠点の資源種類、1/2軒目を入力し、`12→64→64→1` の**同じ重み**で54候補を採点する。後者はv2の公開盤面情報から作る特徴の一部だけを使うが、入力構造とパラメータ数も異なる。したがって、純粋な「GNN vs MLP」比較ではない。

## 最終評価結果

| 指標 | 固定ID型MLP | 共通候補スコア |
| --- | ---: | ---: |
| 教師の選択との一致率 | 21.0% | 66.0% |
| 選択地点の平均pips | 8.93 | 10.37 |
| 教師の平均pips | 10.35 | 10.35 |
| 最良合法候補からのpips差 | 1.44 | 0.00 |
| 最頻交差点IDへの集中率 | 13.0% | 6.7% |
| 選んだ交差点IDの種類 | 21 | 35 |

共通候補スコア方式は学習・調整・最終評価の全区間でpips差0だった。ただし既存の単純なpips最大AIは対局勝率でHeuristicに及ばなかったため、**pips差0はゲーム戦略の優秀さを意味しない**。資源バランス、2軒目との補完、初期道路の方向、港、競合、通常ターンを含む対局評価が未実施。また、最終評価の2軒目は教師が1軒目を置いた状態なので、新方式自身の1軒目の後にどう選ぶかはまだ測っていない。

## 解釈と次の実験

固定ID型MLPは学習盤面で一致率58.3%、未使用盤面で21.0%と大きく落ちた。候補ごとに同じ重みを使う構造は、同じ少量データでも未使用盤面への一般化が良かった。これは固定ID別出力による学習効率低下を示唆するが、PPO停滞の原因を単独で確定するものではない。PPOの長期報酬も別問題として残る。

次の区切りでは、候補スコア方式により**自分自身の1軒目→2軒目→道路**を実際に置かせる。道路は既存Heuristicを維持したまま、同じ未使用seed群で初期配置指標と完走対局のVP・勝率を比較する。候補採点を既存の377 Action IDへ接続するPPO実験やGNN実装は、その結果を見てから判断する。

## 再現と検証

```
.\.venv-rl\Scripts\python.exe -m app.rl.setup_supervised --experiment-id <別ID> --train-boards 600 --validation-boards 150 --test-boards 150 --epochs 40 --architecture mlp
.\.venv-rl\Scripts\python.exe -m app.rl.setup_supervised --experiment-id <別ID> --train-boards 600 --validation-boards 150 --test-boards 150 --epochs 40 --architecture shared
```

記録は `experiments/setup_supervised_mlp_recheck_20260922/` および `experiments/setup_supervised_shared_20260922/`。各フォルダに条件、学習履歴、集計、診断モデルを保存した。追記：本プロジェクトの既存テストは標準の `unittest` で実行可能。2026-09-23時点で新規テストを含む全95件が成功した。
