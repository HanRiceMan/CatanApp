# 教師あり初期開拓地方策の自律配置・完走対局評価

## 実験範囲

前回の[教師あり診断](rl_setup_supervised_diagnostic_2026-09-22.md)で学習した2方式を、教師の状態ではなく**自分自身の1軒目の後に2軒目を選ぶ**評価へ進めた。初期道路と通常ターンは同じ `PolicyCompatibleHeuristicAgent` に固定し、初期開拓地の選択方式だけを変えた。通常UI・既存モデルRegistry・ゲームルール・PPOモデルは変更していない。

未使用seed `32001`〜`32200` を4人のPlayer IDへ均等に割り当て、各方式で同じ200盤面を評価した。相手は `Heuristic×3` と `Heuristic×1 + Random×2` の2条件。比較対象は固定ID型MLP、共通候補スコア、従来Heuristic、単純pips最大。合計1,600対局で非法Action・打ち切りは0。

## 初期配置

| 方式 | 初期2軒の平均pips | 資源種類数 | 最良合法候補からのpips差 | 2軒目の道路先pips |
| --- | ---: | ---: | ---: | ---: |
| 固定ID型MLP | 17.44 | 3.70 | 1軒目1.75 / 2軒目1.68 | 3.11 |
| 共通候補スコア | 20.57 | 3.78 | 0 / 0 | 2.55 |
| 従来Heuristic | 20.55 | 3.93 | 0.01 / 0.02 | 2.73 |
| 単純pips最大 | 20.58 | 3.67 | 0 / 0 | 2.52 |

共通候補方式は自律配置でも高pips候補を選び、固定ID型MLPの低生産・ID依存を改善した。ただし従来Heuristicより資源種類がやや少なく、道路を伸ばした先の候補も少し弱い。候補採点は初期開拓地のみで、道路は全方式で同じHeuristic判断を使うが、置いた開拓地が違うため道路の状況は変わる。

## 完走対局

| 方式 | Heuristic×3：勝率 / 平均VP / 平均順位 | Heuristic×1+Random×2：勝率 / 平均VP / 平均順位 |
| --- | ---: | ---: |
| 固定ID型MLP | 8.5% / 5.50 / 3.04 | 34.5% / 6.89 / 1.87 |
| 共通候補スコア | 22.5% / 6.36 / 2.65 | 47.0% / 7.76 / 1.67 |
| 従来Heuristic | 25.5% / 6.63 / 2.52 | 45.5% / 7.60 / 1.67 |
| 単純pips最大 | 19.5% / 6.36 / 2.73 | 41.0% / 7.43 / 1.77 |

同じseed・学習者ID・席を対応させた10,000回のbootstrap 95%区間（候補方式−Heuristic）は以下。区間は実験内の盤面ばらつきを表し、別の学習seedや別モデルへの一般化を保証しない。

| 条件 | 共通候補の勝率差 | 共通候補の平均VP差 |
| --- | ---: | ---: |
| Heuristic×3 | −3.0ポイント [−8.5, +2.5] | −0.27 [−0.56, +0.02] |
| Heuristic×1+Random×2 | +1.5ポイント [−5.0, +8.5] | +0.16 [−0.19, +0.50] |

差の区間はどちらも0を含むため、共通候補方式がHeuristicより強い／弱いと断定しない。固定ID型MLPは両条件で明確に低い。ただしこの比較は候補別特徴とモデル構造の両方を変えており、性能差を単一要因へ帰属させられない。

## 判断と次の区切り

**GNN導入を急がない。** 共通候補スコア方式は、複雑なグラフモデルなしでも、未使用盤面への初期配置の一般化と完走対局の実用水準を示した。次は固定Action ID 377個と既存合法手マスクを維持しながら、交差点・辺・タイルなど空間候補を共通重みで採点できるPPO方策を小さく試す。その前に、初期開拓地だけの候補方式がHeuristicより資源種類数・道路先候補でやや劣る点を特徴量／道路評価の診断として残す。PPO実験では従来MLPと報酬・相手・seed・step数を揃え、学習速度も比較する。
