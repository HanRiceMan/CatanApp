# 現行最強AIリーグ学習（交渉込み）実験

## 目的

`ppo_gnn_board_65k_s03_exp_v003` と、その上にある初期配置・建設計画・道路・発展・交渉・盗賊判断を組み合わせた現行最強AIを、教師および固定対戦相手として利用する。

現行の377 Action Spaceにはプレイヤー間交渉が含まれない。既存の強い重みを維持するため、Action Spaceは変更せず、提案・承諾・逆交渉を現行の戦略層が自動処理する。交渉後の資源状態と勝敗はPPOの状態遷移・報酬へ反映する。

## 実装

- `CatanEnv`へ固定Opponentの注入を追加。
- 学習者のAction境界外で交渉補助層を実行。
- 75%の局は最強AI 2人＋ルールAI 1人、25%はルールAI 3人。
- 学習者の初期配置は現行GNNを維持。
- 現行AIの選択を教師データとして収集。
- 既存GNNへGraph Family残差を追加。追加直後は既存logitと一致する。
- 既存の道路・開拓地・都市の位置選択を固定し、Family残差と価値推定だけを追加学習可能にした。

## 段階評価

### 377 Action全体の模倣

旧Graph GNNにはFamily補正Headがなく、模倣損失を下げても都市・開拓地・発展などの種類選択を変えられなかった。

Graph Family Headを追加後、教師信号がFamily選択へ届くことを確認した。

### PPO 1,024ステップのパイロット

小規模教師データ（学習8局・検証3局）の後にPPOを行うと、対最強AIの同一8盤面で現行4勝、候補3勝となった。ルールAI戦は両方7勝だった。

場所選択を固定しFamilyだけを更新しても同じ傾向だったため、長時間PPOには進めなかった。

### 教師50局の模倣候補

- 学習40局、1,158判断、交渉補助1,183回
- 検証10局、270判断、交渉補助334回
- 未知検証のFamily一致率: 69.3% → 70.7%
- 未知検証の厳密Action一致率: 40.4% → 42.2%

## 結論

交渉込みの固定最強AIリーグ環境、教師データ収集、Graph Family残差、モデル保存・再読込までの学習基盤は完成した。

ただし今回の候補は現行最強AIを上回っていないため、本番モデルへ昇格しない。アプリで利用するAIは変更しない。

次回は以下の順で進める。

1. 都市待ち時間、開拓地待ち時間、停滞理由、道路目的、盗賊・手札推定など、計画層が利用している要約特徴をFamily残差へ入力する。
2. 模倣の未知局面Family一致率を現状70.7%から引き上げる。
3. 模倣候補が現行AIを維持または上回った場合だけ、低学習率・Family限定PPOを実行する。
4. ルールAI戦と現行最強AI戦の両方で独立100局を通過した候補だけ昇格する。

## Observation v3: 明示的な戦略目標（2026-09-26）

現行ハイブリッドAIの計画をPPO自身へ渡すため、v2の末尾へ155次元を追加した。

- 目標種別（現在は開拓地、都市、発展。最長交易路・最大騎士力の枠も予約）
- 目標交差点54個のone-hot
- 推奨する最初の道路72本のmask
- 目標の必要資源と現在の不足資源
- 開拓地・都市・最短建設の推定待ち時間
- 道路本数、生産pip、資源種類補完、地点価値
- 接続済み候補、待機、停滞、8枚以上、盗賊妨害の状態

`GoalGraphFamilyHierarchicalCandidateMaskablePolicy` は、現行v2 GNNを移植した
直後に同じlogit（浮動小数点誤差1e-7以内）を返す。既存Actorは固定し、追加した
目標Action残差・Family残差を現行最強ハイブリッドAIから教師学習する。

## 追加教材・PPO追試（2026-09-27）

### 一致済み戦略Actionも加える試験

`experiments/goal_strategic_n50_s01_20260926`

修正局面に加え、教師と元PPOが一致していた開拓地・都市・発展購入も残した。
学習752件は開拓地118、都市73、発展73まで均衡したが、追加20局では対最強AIの
平均点が7.00→6.95、順位が2.25→2.35、対ルールAIも9.90→9.80となった。
既に正しいActionを残差へ再学習すると既存Actorへ干渉するため不採用。

### 純粋な修正例を100局へ増やす試験

`experiments/goal_override_n100_s02_20260926`

学習977件・検証292件へ増やし、検証の厳密Action一致率は18.15%まで上昇した。
しかし追加20局では対最強AIが6勝→4勝、対ルールAIが18勝→16勝となった。
模倣精度の上昇と実戦性能が一致しないため不採用。

### 50局教師版から低学習率PPO

`experiments/goal_override_ppo4k_s01_20260927`

100局で微改善だった50局教師版を初期値にし、既存Actorを固定したまま目標残差と
価値推定だけを学習率3e-6で4,096 step更新した。独立8局では現行と全指標が同値。
悪化しなかったが改善もないため未昇格。

次は目標残差を常時加えるのではなく、「計画補正が必要な局面か」を推定する
override gateを学習し、補正の非対象局面への漏れを抑える。

## Override Gate試験（2026-09-27）

`GatedGoalGraphFamilyHierarchicalCandidateMaskablePolicy` を追加した。全action局面に、
元PPOと計画層の最終Actionが異なるかを0/1 labelとして付与し、目標残差を適用する
Gateを学習する。既存Actorは固定した。

`experiments/goal_gate_n50_s01_20260927` の検証330局面では、override率43.9%、
Gate再現率87.6%に対し特異度27.6%で、不要局面にも補正が漏れた。独立8局では
対ルールAIが8勝→7勝となり不採用。

検証特異度80%以上を条件に閾値較正を追加した。閾値0.69では特異度91.9%、
精度68.8%になったが、同じ8局の対最強AIが3勝→2勝。閾値0.75も同じ結果、
0.8では現行と完全同一となり、有効な改善は得られなかった。

さらにGateへ元PPOの15 Action Family logitsを入力した
`experiments/goal_gate_intent_s01_20260927` も、検証Balanced Accuracy 56.6%、
同じ8局で対最強AI3勝→2勝となり不採用。

### 現時点の判断

計画層が既に正しく処理している判断をPPOへ重複移管しても、外側の計画層が
最終Actionを同じものへ直すため上積みになりにくい。残差が非対象局面へ漏れた時だけ
悪化しやすい。今後は計画層の模倣自体を強化目的にせず、計画層を維持したうえで、
相手予測・長期価値・交渉価値など計画層が未処理の判断へPPO学習を使う。
