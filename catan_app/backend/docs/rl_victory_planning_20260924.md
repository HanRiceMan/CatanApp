# 4拠点後の勝利計画（2026-09-24）

## 課題

資源予約付き開拓計画により追加開拓地は未使用100盤面で1.07から2.27へ増えたが、
最大騎士力と最長交易路は低下した。4拠点後に現行PPOへ完全に戻すだけでは、8〜9点で
止まる対局を十分に勝ち切れないため、都市と2点称号の取得順を追加検証した。

## 棄却した都市の長期予約

都市2つ・3つまで鉱石と小麦を予約する候補は都市数を増やしたが、発展カードと称号を
大きく減らした。50盤面で都市2目標は都市0.94→2.20に対して勝率50%→46%、
都市3目標は勝率34%まで低下した。都市だけを固定目標にする方式は採用しない。

## 即時得点と2手先称号

長期の都市予約をやめ、4拠点かつ6点以上で次だけを優先する。

- 都市を現在の手札で購入可能なら、高生産pipの開拓地を都市化する
- 1〜2本道路を追加すれば最長交易路を確定できる時、実際に最長路長を増やす道路を選ぶ
- 最大騎士力まで残り1〜2枚で、使用可能な騎士があれば使用する
- 1枚だけ不足する騎士を狙った発展購入も比較したが、最終候補では強制しない
- それ以外は学習済みPPOへ戻す

道路は公開盤面の各合法候補を一時評価し、自分の最長路長が増えるものだけを選ぶ。
相手の手札や発展カード山札順は参照しない。
